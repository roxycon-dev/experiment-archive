## 结构及工程边界

H 的训练体是 HRNet-W48+FCN，训练时不用冻结 B、旧 MA 头及辅助裁剪损失；完整视野推理复用源 HRDecoder 的全局/局部特征解码几何，单次 backbone 后解码特征裁剪，避免反复运行 backbone。不是完整论文训练流程复现。

U 是官方 ConvNeXt-Small 编码器+项目 U-Net 四级解码，输出恢复到 stride 1；没有加入 RGB 细节支路。HACDR 使用官方 commit 93eb3d41e96f5add9027f1a4977e54eb4fdc9bb0 的 backbone，接项目四通道解码和 BCE+Dice，属于适配候选，不冒称论文复现。

已修复全模型外部迁移、float32 大像素损失归约、梯度累积/AMP 真更新计数、采样及持续 worker 的 epoch 传递。数据缓存有容量上限；二值掩膜 uint8 与 float32 的几何结果一致，损失入口转 float32。
