# 最快训练路径实测记录

RTX4090，1024 crop，有效 batch 8。时间为热身后 optimizer update 的实测值。校准不读取 val、不写训练 checkpoint。

|模型 / 阶段|微批次 × 累积|workers|每更新平均秒|选择理由|
|---|---|---|---|---|
|U1/external_pretrain|2×4|8|0.6151|候选中持续吞吐更快|
|U0/ddr_finetune|4×2|4|0.4649|候选中持续吞吐更快|
|H1/external_pretrain|4×2|4|1.5718|候选中持续吞吐更快|
|A0/ddr_finetune|8×1|4|1.3940|候选中持续吞吐更快|

HRDecoder DDR 会在第一轮 DDR val 之前，对4/8微批次各做16次实际更新校准，按后8次含数据读取的均值选择，记录 H_DDR_selection.json。外部阶段8微批次GPU就绪中位数1.3538秒，但含外部图像读取的均值1.6803秒，不能把该中位数冒充DDR平均速度。

初始U微批次2单次更新3.65–4.50秒；快速kernel、持续workers、原始数据缓存和uint8二值掩膜共同减少开销。没有降低1024 crop或2048验证视野。Batch Dice受微批分组影响，因此在新验证前选定并锁定，同模型配对沿用选择。

复用历史U0的12k结果，H0已做6k且没有恢复权重，避免无收益重启。外部可用监督仅48train+6dev，在新val前统一缩短到2400更新；DDR仍保留12k学习日程和完整76张验证，只在半程后停滞且无类别优势时提前停止。

当前实测U1外部2400更新总计1399.57秒（约23分20秒），包含验证和保存。U1 DDR已完成12k：总耗时6029.81秒（1小时40分），最佳val mIoU 36.6934%。表中校准时间不等于正式总耗时。历史U0总耗时13758秒，当前单阶段用时约其43.8%，只是描述性比较，不能把实现/预训练等变化的影响单独归因。
