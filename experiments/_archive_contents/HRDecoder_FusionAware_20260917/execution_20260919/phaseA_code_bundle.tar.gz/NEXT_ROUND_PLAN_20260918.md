## 1. 证据地基（为什么是这几条路）

上轮与历轮的**可靠结论**（全部有落盘证据）：

1. **B 臂（0.5·student + 0.5·融合概率监督）四时间点全面领先 A**（+0.0007/+0.0007/+0.0008/+0.0011），但 max 差 0.0008 << gate 0.003——方向真实、效应量弱。
2. **两臂均在 iter3000 见峰回落**（A: 0.4167→0.4131；B: 0.4175→0.4142）→ 本轮 T=3000，不再训到 4000。
3. **噪声地板（历史实测）**：seed σ≈0.0019（V1，3 seed）；图像级配对 CI 半宽 val≈0.0023、test≈0.0013；checkpoint 波动中位 0.0093。**任何 <0.002 的差异不可用于选方案**（上上轮 F1 的教训：CI 跨零的第一名被 test 证伪）。
4. **冠军集成是本项目唯一稳定的大增益来源**（D 0.4161 → champion val 0.4267，+1.06 点，来自成员多样性而非单模型强度）。
5. 数据盘已有资产：`runs/r1/ckpt_B_s42/iter_{1000..4000}.pth`（融合监督学生，各 718MB）、refcache 454 张（fp16 2048²）、A 臂全部检查点。**E-0 路线零训练成本即可开打**。

## 2. 实验设计（四阶段，串行，每阶段有预注册 gate）

### E-0 · 集成扩展探针（零训练，~1.2h，本轮性价比最高的牌）

**假设**：融合监督学生 B_s42@3000（val 0.4175，独立于现有 D/E/B/E4 成员的训练轨迹）能为冠军集成提供多样性，即使其单模型强度仅 +0.0014。

- 构建 6 成员冠军：`D(w3)+E(w2)+B(w1)+E4(w1)+B_new(w1)`，h4 MA 头与翻转 TTA 不变。
- val 扫描（各 ~4.5min）：基线 5 成员（复算，校验逐位一致）；+B_new@3000 w1；+B_new@3000 w2；+B_new@4000 w1（对照峰值点假设）。
- **G0 门**：最优 6 成员 val ≥ champion + 0.002（高于 val 图像级分辨率 0.0023 的一半，且显著低于 seed 噪声——**过门后仍须 test 确认，val 过门只是入场券**）。
- 过 G0 → 立即 test 确认（~14min），test 若 ≥ champion test + 0.001 → 锁定为新冠军，后续阶段以新冠军为基线。
- 不过 G0 → 记录为「B_new 无多样性增益」的否定结论（这本身是重要信息：说明融合监督学生与 D 成员高度冗余），继续 E-1。

### E-1 · 融合监督变体筛选（2 新臂，~2.2h）

**假设**：0.5 固定权重不是融合监督的最优点；融合概率主导或课程式调度能放大 B>A 效应。

- 三臂对比（全部 T=3000、seed42、lr 5e-5、其余同上轮）：
  - **V0（复用）**：w=0.5 固定 —— 上轮 B 臂数据直接引用（0.4162/0.4169/0.4175），不重跑；
  - **V1（新）**：w=1.0 融合概率 Dice（student 分支权重降为 0，纯融合监督）；
  - **V2（新）**：课程调度 w: 0（前 1000 步）→ 0.5（1000-2000）→ 1.0（2000-3000）。
- 每臂 4 val 点照旧（1000/2000/3000 + 补 iter1500 半程点**不加**——保持与上轮口径一致，避免横向对比失配）。
- **G1 门**：变体 max val ≥ **0.4185**（= D + 0.0024 ≈ V0 峰值 + 0.0010，即必须实质性超越 V0 而非噪声领先）。多臂过门取最高；全部不过 → E-2 跳过，直接 E-3（用 V0@3000 做 E-0 式扩展尝试，若 E-0 已失败则本轮收场汇报）。

### E-2 · seed 稳健性（胜出变体 + A 对照，2 臂 ~2.2h）

**假设**：V0 的 +0.0008 若是真实效应，在 seed43 上应复现方向（不要求复现幅度）。

- seed43 跑胜出变体 + A 对照（各 T=3000）。
- **判定（非硬门，写给 E-3 的采用依据）**：
  - 强证据：seed43 变体−A 的 Δ>0 且两 seed 合并 Δ ≥ 0.0015 → E-3 采用变体学生；
  - 弱证据：方向反转或合并 Δ<0.0015 → E-3 只用 V0/B_s42 检查点（已在盘）。
- **预注册披露**：2 seed 的功效有限（σ≈0.0019 时检出 0.0015 的功效不足 50%）；此阶段目的是**方向复核**，不是显著性证明。不设第三 seed——预算留给 E-3。

### E-3 · 最终集成 + test 确认（~1.5h）

- 候选（val 单次遍历统一算，~5min/config）：
  1. 现冠军（基线，必含）；
  2. E-0 最优 6 成员（若过 G0）；
  3. E-1/E-2 胜出学生加入的 6 成员（w∈{1,2} 扫描）；
  4. 「7 成员」：E-0 与 E-3-3 同时加入（若各自有增益且互不抵消）。
- **G3 门**：val 最高者 ≥ 冠军 + 0.002 → 锁定（val 定序、test 定胜负，锁后不改）。
- test 确认（~14min）：报告全部候选 test mIoU + MA，锁定方案自对照配对 CI；test 领先但 CI 跨零 → 如实写「未达显著」，不宣称胜利。
- 不过 G3 → `stopped_no_gain` 诚实收场。

## 4. 运行保障（全部复用已验证机制）

1. **run_guarded.sh**：EXIT trap（tar 备份 → 3×shutdown）+ 台账 deadline + timeout 包裹，每阶段重启自动重算剩余预算；
2. **watchdog**：独立进程，台账到期强制关机（fail-closed）；
3. **auto_resume.py 决策树**：意外中断后自动「证据快照 → 分支决策 → 止损关机」，杜绝无人值守下的费用泄漏（上轮 08:26 实战验证：2 分钟止损）；
4. **arm_credit 重启补丁**：按剩余工作量感知预算（本地 76/76 单测绿，随本轮部署）；
5. DEVIATIONS.jsonl：任何偏离本方案的运行时决策必须落条目，含理由与影响面。
