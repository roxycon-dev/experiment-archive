# 补充实验固定协议 v1（2026-10-23）

范围：先完成基线追溯、最终系统四行对照、MA 病灶分析和独立数据使用历史核查。此阶段不新增训练、不搜索阈值/权重、不设计模型。所有预定对照均报告，包括下降和零差异。本文档在任何本轮测试推理前建立；已有历史测试使用仍须披露。

## 模型和像素指标

- 四通道 EX、HE、SE、MA；标注 ID 1、2、3、4；0 为背景，255 为忽略。
- 固定 DDR split613：454/76/227 张，以原始图像身份及历史 SHA 清单核查。原图坐标、FP32 概率、严格 `p > 0.5`，逐图 int64 TP/FP/FN，全局累加后逐类 IoU 和四类宏平均。MA precision/recall 另列。
- A 为 D/E/B/E4 按 3:2:1:1、原水平翻转协议及原 H4 MA 修正头组成的旧系统。A_pre 使用同一次前向得到的修正前概率，绕过 H4，其他不变。U 为历史 ConvNeXt U0。S 为 seed42 S20 EMA。C 为同父模型、同节点 seed42 C20 EMA。
- 完整系统严格沿用运算顺序 `0.75 * (0.75 * A + 0.25 * U) + 0.25 * S`。
- 去 H4：`0.75 * (0.75 * A_pre + 0.25 * U) + 0.25 * S`。
- 去 U：原绝对权重 A=0.5625、S=0.25 按剩余总和 0.8125 归一化，`(9/13)*A + (4/13)*S`；不调比例。
- 换 C20 EMA：`0.75 * (0.75 * A + 0.25 * U) + 0.25 * C`。不使用较早 Q16 代替。
- 原基线须为 split613 seed42 best_mIoU_iter_32000，并核对配置和权重身份。若找不到则明确缺失；其他划分/种子/节点的权重不能冒充原基线。需要复现训练时单独标识。
- 完整系统复现结果须与历史逐图计数核对；不一致则暂停结果解释并定位环境/实现差异。不得通过搜索设置贴合分数。

## MA 病灶指标（在看到本轮预测前固定）

- 仅分析 MA 通道；真值及预测各自按 8 连通域定义病灶；保留 1 像素病灶，不做开闭运算或小区域删除；忽略像素在连通分析前排除。
- 候选匹配为原图上组件 IoU >= 0.10。按最大匹配数、再最大 IoU 总和进行二部图一对一匹配；完全相同的匹配以稳定组件 ID 决定。合并预测最多匹配一个真值，其余为漏检；分裂预测最多一个匹配，其余为误检。
- 病灶检出率 = 匹配真值数/全部真值数；每图误检数 = 未匹配预测组件总数/全部图像数（包括 MA 阴性图）。另报告病灶 precision、MA 阳性图数量与绝对计数；像素 recall 单独标注。
- 面积分组仅由 DDR 训练集真值 MA 组件面积的 1/3 和 2/3 分位数决定，采用 nearest 取值；small <= q1，medium q1 < area <= q2，large > q2。若边界相同，报告空组，不改边界。所有比较共享边界。
- 三套主比较：可信原 HRDecoder、完整系统去 H4、完整系统。基线缺失时可完成另外两套，但不能称三套比较已齐全。
- 例图规则：按 sid、真值/预测组件 ID 升序，每类取前 3 例。恢复 = 完整匹配而去 H4 未匹配的真值；仍漏检 = 两套均未匹配；新增误检 = 完整系统未匹配预测组件且与去 H4 任一预测组件无像素重叠。例图附原图、真值、预测、面积及匹配状态，不以审美或分数挑图。
- 统计：成对图像 bootstrap 2000 次、固定 seed=20261023；若获得可信患者身份则按患者为单位，不能由文件名前缀猜患者。区间不代表训练种子变异。

## 独立验证与效率

- 候选队列须先核对整个项目训练、选型、调参和评估历史；同时核对标注定义、类别完整性、精确及近似重复和患者身份。未知历史不等于独立。
- 数据集、图像清单及输入几何在推理前单独锁定；三套模型为原 HRDecoder、C20 替换系统、完整系统。不得微调、重选阈值、重选融合权重。若无法证明独立，保留缺口。
- 完整系统计时包含所有专家实际前向、TTA、MA 头、对齐与融合，并区分输入读取、GPU 同步计算、输出落盘；缓存伙伴测时仅算缓存重组。另报告各模型参数、完整常驻/顺序执行显存、权重及缓存体积。多卡吞吐和单图延迟分开。
- 服务器先只读盘点 GPU、进程、环境、数据和权限，仅使用空闲资源；不停止他人进程、不更改账户密码、不关机。
