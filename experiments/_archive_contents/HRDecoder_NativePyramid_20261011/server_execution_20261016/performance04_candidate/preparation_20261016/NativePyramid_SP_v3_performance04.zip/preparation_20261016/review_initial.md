## 可保留但仍需重新验收的实现

- data 的 RGB、label最近邻、ignore旋转边缘/padding、独立RandomState和seed42+epoch均匀454置换方向符合继承协议；需新测试确认标签/几何、全ignore与原黑边处理。
- metrics 累计TP/FP/FN、忽略255、不算背景和四类算术均值正确；空阳性图FP会计入。
- evaluation 原尺寸先插值FP32 logits，`logits>0`与数值上sigmoid后严格>0.5在极小正值处可能有浮点差异。设计要求推理时sigmoid并严格比较，建议照字面执行以锁定评估器。
- 预检输出如不是完整PASS，应明确保留 INCOMPLETE/FAILED 并阻止正式入口；本地静态检查不能生成或代替服务器preflight PASS。

## 最终复审和服务器验收边界

最终复审应重新逐文件查看完成源码，并核对新增有意义单元测试：独立损失数值基准、非均匀阳性/有效数的micro1×2一致、空正组固定系数、平分值索引、单图ignore、极端logit梯度、Norm通道轴、四直接路径等价/初始化零残差、监控两组学习状态与PAUSED/失败恢复、actual test file SHA。
