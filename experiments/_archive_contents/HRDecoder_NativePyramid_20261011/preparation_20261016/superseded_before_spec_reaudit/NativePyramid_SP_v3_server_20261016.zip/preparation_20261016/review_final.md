# v3 训练准备独立复审

日期：2026-10-16。结论：**当前实现可作为服务器预检候选交接；本地准备通过静态独立复审，不等于已获正式训练 PASS。** 本次复审未发现仍阻止接机预检的已知架构或执行协议偏离。最终源码身份以最后一次本地检查及交接清单记录的 SHA 为准；源码或依赖变化后必须重新检查，不能复用旧身份的结果。

## 阅读范围和证据边界

独立子代理完整阅读 v3 设计文档及继承的 v2 执行协议，先审查旧代码形成 `review_initial.md`，再只读复审完成后的 `model.py`、`losses.py`、`data.py`、`metrics.py`、`monitoring.py`、`train.py`、`evaluate.py`、`verify.py`、三个单元测试文件、`protocol.json`、`requirements.txt`、`run_checks.ps1` 与新版 README。

本子代理只进行了源码审查和审查文档写入，没有运行真实数据 SGD、裁块学习、高分辨率训练或 test。主代理运行的本地单元检查应由实际保存的报告证明，本审查不把其口头进度当作独立执行结果，也不继承任何 v1 `evidence*` 的 PASS。当前没有 v3 正式 val/test 或性能达标证据。

## 已核对的实现

|范围|复审结果|
|---|---|

|损失与微批|P/K/A/V从完整两图先计算；微批共享分母、仅累加自身分子、不再乘1/2；正负固定0.25、dense0.05、aux0.2，四类平均、仅阳性图Dice；OHEM平分按原阴性展平索引；S/Z独立选难负例。全ignore图可贡献图连接零，整batch全ignore拒绝；图连接零不再对ignore logits求和。|

|监控|正常反传读取现有梯度缓冲区，记录模块及四尺度×四类别裁剪前后范数，无额外反传；探针分别记录S/Z累计计数、阳性logit及直路/C/D幅度。探针和val独立建立4k起连续两节点recall≥5%的学习证据，再连续两节点≤0.1%判丢失；探针未学会三次TP=0须近1000更新有该类监督；val峰值回落≥15pp另行暂停。|

## 首轮发现的修复闭环

初审指出的旧逐图均值/空正组权重转移、非稳定topk、旧监控阈值、弱裁块门和两步高分辨率冒烟、未验test实际文件、依赖与验证器身份缺失、旧GN/version1配置均已替换。复审追加指出的弱stage PASS放行、micro2未匹配真实2048预检、test锁与checkpoint内部val未绑定、NaN锁值、ignore求和零及并行运行风险已落实对应约束。

新版 README 已区分当前实现、本地结构检查、服务器预检、正式40k与历史v1，给出全新输出目录、PAUSED续接和锁定test的操作入口。诊断门失败不能降门槛、改步数或沿用旧PASS。

1. 接机核对 GPU/BF16、驱动/显存/设备身份、磁盘与数据/权重文件；保存实际环境证据。当前运行时函数记录的字段不能冒充所有驱动细节均已锁定。
2. 在该服务器执行指定W48逐键身份与固定BN检查，并运行实际W48的FP32/BF16、无重算/重算、batch2/micro1的S/Z/loss/全部梯度对照。包含零残差起点与丢弃的非零残差接线fixture，容差预先锁定，失败不能事后放宽。
3. 固定8块真实256裁块、每类至少两块阳性；256更新，224/256各类IoU均≥20%，末16次loss均值低于首16次；诊断权重丢弃，成本另记。
4. 固定覆盖四类的真实2048图组，8次global batch2、micro1更新；检查首次末层/直接路径任务梯度、末层实际更新后的内部任务梯度及参数变化、四类响应、BN buffers不变和BN affine可学习；记录真实显存峰值与更新耗时。weight decay引起的参数变化不能代替任务梯度证据。
