# HRDecoder C/S实例采样实验最终报告（2026-09-20）

## 结论

本轮没有产生可保留的测试集提升。历史冠军在固定测试集上的 mIoU 为 **44.2115%**；在验证集锁定的 `0.75×冠军 + 0.25×C@2000` 最终测试为 **43.8064%**，下降 **0.4052 个百分点**。因此不能把验证集上 0.1963 点的表面提升写成有效改进，也不再以测试结果调整节点、权重或阈值。

实例均衡采样 S 相对匹配对照 C 在 4000 步时提高 **0.6591 个百分点**，说明采样干预确实改变了学习结果；但其独立输出只有 39.8320%，且与冠军固定融合后验证集下降。这个方向不足以承担“提高5个百分点”的目标，应停止继续加步数、换 seed 或扫描融合权重。

## 协议与身份

- 数据划分保持 454/76/227；测试集只在验证集方案锁定后运行一次。
- C、S 均从同一个 D@2000 student 和 B reference 初始化，seed=42、4000步、SGD、相同学习率和可训练范围。
- C 使用原混合前景裁剪；S 的一半样本按四类均匀选择图像和连通病灶实例，再做带随机偏移的实例保留裁剪。
- 独立 student 通过 `_student_prob` 评估；未误用模型默认的 reference/student 0.5 融合。
- 主指标为四个 sigmoid 通道严格 `p>0.5`，全数据集累计 TP/FP/FN 后计算四类 IoU 均值。
- 历史冠军同机复现验证集 42.6694%，测试集 44.2115%。冠军组成及全部输入权重均记录 SHA256。

## 研究判断

1. **普通续训退化是真实问题。** C@2000略高于D起点，但到4000明显下降；训练损失没有提供可靠的整图泛化选点信号。
2. **实例均衡采样只解决了“窗口里有没有病灶”，没有解决类别条件下的错误类型。** S 增加了病灶暴露，主要推高 SE；EX/HE 没有共同改善，MA也未稳定提升。
3. **当前冠军对同族 student 的互补性不足。** 四个候选固定融合中三个下降，唯一验证集小峰值没有在测试集复现。继续扫描融合权重会放大验证集选择偏差。
4. **剩余约3个 mIoU点无法靠这一采样改动补足。** 下一轮若继续追分，应改变信息来源或监督质量，例如经过质量门槛的同域像素级半监督/新增真实病灶标注，或真正异构且单独收敛的模型；不建议继续在 C/S 上延长、换 seed、叠加损失或动态阈值。
