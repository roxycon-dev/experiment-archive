# 下一轮 GPU 效率要求

用户于 2026-10-03 补充：本轮接受当前 GPU 占用波动，下一轮希望 GPU 尽量持续全功率运行，占用曲线稳定接近最高。

本轮继续执行已经冻结的模型、微批、优化器、采样与日程，不为占用曲线改动正在运行的实验。

下一轮正式训练前，将 GPU 效率纳入必要验收：

- 在真实数据与完整前反传下定位取数、解码、传输、同步和日志/断点开销，避免只看利用率推断瓶颈。
- 在正确性与显存约束内调整数据缓存、预取、pin memory、异步传输及实际微批；所有配对实验使用相同、事先冻结的设置。涉及微批 Dice 定义的变化必须在正式前记录。
- 使用持续稳态区间记录每有效更新秒数、数据等待、峰值显存与 GPU 占用曲线；以提高有效训练吞吐、缩短完成时间和稳定高占用共同验收。
- 不通过无关计算、无意义额外更新或改变训练问题制造满载曲线；验证和必要存档阶段单独记录，不能承诺全部时刻都达到 100% 占用。

这是下一轮的效率偏好与执行约束，不是授权现在追加新实验。
