# 审查循环与变更记录：当前v3候选

2026-10-08。没有训练、真实模型推理或优化器更新。此前v1→v2记录保存在[archive/v2/03_审查与变更记录.md](archive/v2/03_审查与变更记录.md)。

## 循环一：用户质疑触发机制复核

1. **三阶段目标稀释成立。** 初始相同输出时，普通KD对共同方向等价于`.71875A+.15625U+.125S`；v2实际置信度权重对应像素相关的有效目标。分支参数仍有不同梯度，因此未证明永久塌缩，但撤回“逐级学习已经有机制保证”的表述。
2. **容量不足是合理风险，尚非已证因果。** S20推理保留DINO骨干及空间交互；10万参数小头不能被描述成其等价替身。历史没有W48容量阶梯对照，不据此宣称扩容必涨。
3. **旧H4并非OOF。** 输入来自同train成员预测；detach不能改变样本独立性。学生取消尚未验证的在线H4，旧H4留在最终教师中；不声称整个系统因而无过拟合或训练内KD风险。
4. **精度与论文主张降格。** 45.36/45.86保留为目标，43～44.5也不作为有数据支持的区间。Hydra及相关先例使“多头/残差/KD组合”不足以直接主张新颖性。

补证据由原GPT-6-Luna max子代理核查；核心方案由主代理设计。[教师身份](evidence/round3_teacher_identity.md)、[历史机制](evidence/round3_history_mechanism.md)、[H4独立性](evidence/round3_h4_independence.md)

## 循环二：v3候选及反方审查

将级联三分割输出改成唯一最终分割；两条私有局部/全局路径保存有符号分歧，分类器可以利用其表示；辅助梯度只直接更新私有参数。增加实际私有容量，低分辨率放较大参数，子像素读出替代粗图插值残差。

反方复审进一步限制主张：

- dU/dS逆式正确，但它只是教师输出的坐标变换。
- 相同隐藏图配上不同读出bias也能得到不同分歧；最终分类器还可以忽略它们。主文加入具体反例，未追加未经证实的正交/互斥惩罚。
- 梯度路由是按参数块指定的更新场；它防止辅助梯度直接进入主干，不能防止私有目标竞争或未来轨迹的间接变化。
- 同初始化属于执行要求，当前没有SHA和历史逐张量复现证据。
- `lambdaD=0`对照明确保留全部私有路径/读出/融合；同图成员坐标对照与真正Hydra家族对照分开，不冒充原论文复现。

审查记录：[目标](evidence/review_v3_objectives.md)、[协议](evidence/review_v3_protocol.md)。其早期参数静态计数漏两层全局投影，已追加更正；以模块实例结果为准。

## 循环三：把容易空泛通过的检查改成有效反例

新增模块CPU原型最初在零末层处验证路由，这时主任务通过私有路径的梯度为0，检查不够有区分力。主代理审阅后要求独立非零末层诊断副本，并切断z0捷径，确保测到真正的私有路径梯度。

加强后的结果：

| 检查 | 结果与限定 |
|---|---|
| 参数实例与层定义 | L 2,918,816；G 3,459,872；两个分歧头4,224；融合36,736；总6,419,648 |
| 新增前向MAC | Conv/Linear42.549G，attention QK/AV2.147G；总44.697G，解析2048尺寸；未运行2048前向 |
| 零步恒等 | 新增分类末层为0时，输出精确等于给定z0；不代表历史训练轨迹复现 |
| 分歧首步隐藏梯度 | 非零；没有零门×零输出层造成的永久死路径 |
| 子像素读出 | PixelUnshuffle/Shuffle互逆；可以表示4×4格内交替残差；不增加原图信息 |
| 非零末层、z0 detach | 主任务仍经私有路径到共享特征与参数；相应范数约0.00179/0.00204 |
| 未路由辅助梯度 | 对共享参数范数约0.00877，证明若普通backward确会进入共享主干 |
| 实际路由 | 主干/分类器梯度相对task-only差0；私有梯度相对task+aux差0，且两项都非零 |
| 参数更新 | 只有独立诊断副本设定非零末层；未执行optimizer step，原零初始化保留 |

目标与实际损失另有**18项CPU float64检查通过**：混合目标等价及其范围、分歧逆式、同均值不同符号反例、读出不同而隐藏相同、输入信息误差下限、最终输出可忽略分歧、mask不变性、teacher detach、空有效域、权重界及日程。它们包含证明局限的反例，不全是“模型有效”的正向检查。

结果：[模块检查](evidence/v3_module_checks.json)、[目标/损失检查](evidence/v3_objective_checks.json)。没有完整HRNet、真实病例或教师前向。

## 仍未关闭的问题

1. 454张train教师缓存尚缺，不能证明训练分歧有足够能量/秩；验证融合收益不能代替此证据。
2. 642万随机新增参数、4层全局注意力用同SGD在40k内是否学好未知；不得按参数量推导收敛或精度。
3. 2048缩放的信息损失仍存在，子像素输出无法复原未观察到的细节。
4. 同容量仅最终KD可能一样好或更好；有符号分歧可能只是噪声或等价坐标，创新假设可能被否定。
5. 真实GPU资源、完整接口和数据几何尚待实现核验；历史test非新盲测。

本轮没有发现尚未处理的确定代数/接口规格矛盾；以上是实质研究风险。继续凭文字更换模块不会把它们变成已证收益。v3作为可审查候选交付，不授予“完美”“保证超越”或“顶刊可录用”状态。
