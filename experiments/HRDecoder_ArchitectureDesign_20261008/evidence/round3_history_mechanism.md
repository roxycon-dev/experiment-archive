# 第三轮历史机制证据补审

范围：只核对 E4、MA/HE 头、RGB 专家、高分辨率候选、S–C 与异构融合等已有记录，判断它们对分支容量、级联教师和在线 H4 能说明什么。没有训练、重新评估或改动历史资产。引用路径相对于 `D:\dataset\experiment`；行号为原文件行号。

## 结论先行

历史结果**不能把失败归因为“共享 W48 骨干容量不够”**。档案里没有在相同 ImageNet W48 起点、数据、训练步数、损失和推理条件下，只改变共享宽度/分支容量的匹配试验。E4、A、MA RGB 专家和 M1 细节路都没有证明“多加容量就有效”，但它们也不是共享 W48 容量的严格反证。最强的正向结构对照是 DINO 的 S–C：相同父权重和 32k 预算下，空间交互臂单分支验证高 1.2459 pp；这验证的是该 DINO 空间交互改动，不是 HRNet 加宽。

历史也没有训练过“逐级级联的多个教师监督”或“在线更新分支上的 H4”。可用证据分别是单个冻结参考的输出级融合监督，以及在固定多模型预测上训练的小型 MA 后校正头。它们不足以决定删除级联中间教师或取消在线 H4。

## 分支与容量：负结果存在，容量因果没有被隔离

| 历史实验 | 可核对事实 | 对机制归因的边界 |
|---|---|---|

| **R6/R6b：RGB MA 专家** | 从 RGB patch 单独训练 U-Net 式专家，没有主干病灶先验。R6 512² Dice+0.5BCE 曾长段 patch IoU=0，α=.3 最佳 MA val IoU .2438，对照冠军 .2597；R6b 改256²、Tversky(0.3,0.7)，2k内 best patch IoU .0563，最佳融合 MA val .2431，仍低于 .2597。末段 loss 仍降，预算只有2k。[`HRDecoder_FusionAware_20260917/ROUND6_RESULT_20260918.md:11-18,31-40,44-69`；同轮原始阶段表：`HRDecoder_FusionAware_20260917/HRDecoder-DDR-阶段成果报告-20260917至0918.md:71-80,87-103`] | 反对“从 RGB 独立训练小专家，短训后即可补 MA”的具体配方；不测试共享 W48 上的额外分支，也不能区分专家弱、训练不足和目标/采样问题。不能据此断言所有图像条件分支都无效。 |

因此，已有失败最多支持“未经匹配验证的额外分支不保证收益”。历史没有把“容量不够”与细节可辨性、语义条件、稀疏正例优化、训练预算或推理几何分开。E4/A 的诊断材料特别指出低对比度、血管混淆、正负监督和定位等仍可能解释表现；既有报告没有梯度或容量饱和测量。[`HRDecoder_诊断调研_20260910/HRDecoder_诊断与押注建议.md:17,21,35-41,68-70`]

## 高分辨率：验证信号与测试结果必须分开

- 2026-10-02 的配对续训是 **ConvNeXt-S U0**，不是 HRDecoder/W48。2048 控制臂实际训2k、best@1k；随机2048/2560高分辨率臂训4k、best@1k。固定“旧冠军75%+候选25%”下，控制融合 val 43.3663%（相对既有融合−0.1214 pp），高分辨率融合43.7328%（+0.2451 pp）；单模分别39.0864%和39.6065%。这是 val 上对高分辨率续训的有限正信号，未测 test，两个臂最终更新预算不同。[`_全实验档案_20260920/05_高分辨率配对续训_20261003.md:3-14`]
- 后续 G 阶段对高分辨率 U0@1000 固定25%候选的完整 val 为43.8679%，旧完整部署43.4877%，差+0.3802 pp；该候选一次锁定 test 为44.634452%，旧部署44.780891%，差−0.146440 pp，配对 bootstrap 95%区间[−0.4094,+0.0948] pp。[`HRDecoder_Next_20261003/reports/G_阶段结论.md:3-17`；`HRDecoder_Next_20261003/reports/HRDecoder_严格实验最终报告_20261003.md:1-18`]
- 这是异构 U0 候选和完整旧部署的组合/几何结果；G 记录还对 whole/slide、native/long2048 做了不同推理路径比较。[`HRDecoder_Next_20261003/reports/G_阶段结论.md:5-22`] 因而不能把“val升、test略降”解释为共享 HRNet 分支容量失败，也不能把该验证增益迁移成单 W48 的预期收益。
- 另一条真正的 W48 高分辨率例子 D，是从 DDR 训练的 B@3000 初始化局部学生，每个1024 tile重新编码，并与冻结 B 整图参考各占0.5；best@2k val41.615%，test42.576%。这不是 ImageNet 直启学生单模，也不是只增大一个分支的隔离实验。[`_全实验档案_20260920/02_HRDecoder逐实验事实档案.md:48-49`；实现审计：`HRDecoder_ArchitectureDesign_20261008/evidence/h4_code_audit.md:40`] 它说明局部编码+参考预测的复合路线能达到该结果，不能单独证明局部编码提高了共享主干容量。

## 有效的正向机制证据：S–C 与异构概率融合

**S–C 是较强的匹配单分支证据，但不是容量对照。** C、S 从同一 F12 原始权重出发，均训32k，使用同一 DDR 采样、增强、学习率；C 只继续训练，S 只加空间交互。[`HRDecoder_FinalDecision_20261005/最佳模型技术报告/报告正文.md:181-187`] 20k 单分支 C=41.0244%、S=42.2703%，差+1.2459 pp；32k 差+1.0451 pp。固定已有 P0 后，20k/32k 的系统差分别只有+0.1456/+0.0974 pp。训练用 GT BCE+Dice；此处没有教师特征蒸馏。[`HRDecoder_FinalDecision_20261005/结题报告/evidence/historical_experiment_ledger.csv:76-77`；`HRDecoder_FinalDecision_20261005/最佳模型技术报告/报告正文.md:189-223`] 结果支持“这套 DINO 空间交互在当前匹配条件下改善独立分支验证”，不能推出“HRNet W48 容量不足”，也不能把单分支增幅等量搬到融合系统。

**ConvNeXt U0 的弱单模分数与强 HRDecoder 系统融合是异构互补的直接例子。** U0 单模 val38.4464%；按固定 P0=0.75 C_old+0.25 U0，P0 val43.4877%、test44.7809%，比同次 C_old 重导出的 test44.2110%高0.5699 pp。[`HRDecoder_FinalDecision_20261005/结题报告/HRDecoder项目结题报告.md:126,130-132`；`HRDecoder_FinalDecision_20261005/最佳模型技术报告/报告正文.md:95-105`] 这说明独立分数较低的不同架构可提供互补预测；这是两个完整独立模型的概率融合结果，不是从一个共享 HRNet 主干复制出较大分支的证据。最终 P0+S 固定融合 test45.8604%也仍是多模型系统输出，不是单网络成绩。[`HRDecoder_FinalDecision_20261005/结题报告/HRDecoder项目结题报告.md:15,130-132`]

## 教师、feature KD、detach 与 H4 的历史边界

1. **没找到 feature KD 或逐级级联教师的已完成对照。** R1 只比较学生 Dice 与“学生/单个冻结 B reference 的概率平均再对 GT 算 Dice”：同从 D@2000 起，两臂各4k，B臂 best val .4175 对 A .4167，+0.0008 mIoU（+0.08 pp），未过+0.003门槛、无 test。[`HRDecoder_FusionAware_20260917/HRDecoder-DDR-阶段成果报告-20260917至0918.md:29-39`] R5 的 V1 纯融合监督在 seed42@3k 达.4187，seed43方向复核 best.4179；但作为冠军第六成员只增约.0006 mIoU，无 test。[`HRDecoder_FusionAware_20260917/ROUND5_RESULT_20260918.md:36-62,68-75`] 这些是预测/损失层的融合监督，不是中间 feature KD，也不是 T0→T1→T2 级联教师对照。没有实验证据支持或反对移除级联中间 teacher；只能说相邻的单-reference输出监督结果较小且未证 test 增益。
2. **实际 gradient isolation 主要来自冻结整套参考模型，不是在线共享支路 detach 消融。** 旧 H4 训练把 D student 和 B reference 置 eval、参数冻结，推理 logits 在 no-grad 下计算，只更新头部参数。[`HRDecoder_ArchitectureDesign_20261008/evidence/h4_code_audit.md:9,16-20`] R1 的 B reference 也冻结。[`HRDecoder_FusionAware_20260917/HRDecoder-DDR-阶段成果报告-20260917至0918.md:31-38`] 我未在本轮核对的历史实验中找到“相同共享主干下，对 branch KD loss 开/关 stop-gradient”的匹配试验；不能把冻结教师等同于 v2 中让同一在线支路继续受主 GT 损失更新的 detach 设计。
3. **静态 H4 对 MA 有真实收益，但在线 H4 没有被历史直接测试。** H4 是3361参数的 MA 后融合小头，输入固定 D/B 与融合概率，头训练时基础预测被冻结。D+reference test从42.5764%到43.4287%（+0.8523 pp），MA IoU从24.7290%到28.1383%，其他三类逐位不变；接完整 D/E/B/E4 集成的原始 H5/H7 test从43.2289%到44.2115%（+0.9826 pp），MA从24.7255%到28.6558%，非 MA 计数不变。[`HRDecoder_审查轮_20260916/audit_runs/audit_20260916_A/experiments/h4_test_confirmation.json:3-14,38-75`；`HRDecoder_FinalDecision_20261005/结题报告/HRDecoder项目结题报告.md:122-126`；训练冻结条件：`HRDecoder_ArchitectureDesign_20261008/evidence/h4_code_audit.md:16-24`] 这反对“历史 H4 全无价值/可因旧失败删除”的说法，并支持其**固定底座上的 MA 专项校正**。
4. H4 的正结果不能证明“在线 H4”有同样作用：历史头看到的是已固定 D/B 概率分布；新在线分支若共同更新，H4 输入分布也变。旧 H4 代码/评估审计指出这项输入合同差异，但这是迁移边界，不是在线训练失败证据。[`HRDecoder_ArchitectureDesign_20261008/evidence/h4_code_audit.md:9,19,24-26`] 反面上，H4式 HE 头 best val43.60%低于冻结基线43.76%，没有 test；它只说明 MA 的收益不能泛化到 HE，不否定 MA H4。[`HRDecoder_FusionAware_20260917/ROUND6_RESULT_20260918.md:13-15,31-34`] 所以历史对“取消在线 H4”没有直接裁决：删除旧校正概念与取消在线版不是同一个命题，后者尚无匹配实验。

## 面向三项争议的证据归纳

| 争议 | 明确支持/反对的历史证据 | 尚未被历史回答的部分 |
|---|---|---|
| **做更大的分支** | 反对“分支越大/越多就会涨点”：E4、A、R6/R6b、M1 detail path 都没有提供预期的独立增益；其中 E4/A/R6还存在语义条件、训练和正例稀疏等限制。S–C 对照支持某一套空间交互结构有用。 | 没有同起点、同训练量的共享 W48 宽度/通道容量阶梯，也没有消融证明表示容量已饱和或不足。故“容量不足”既不是已证瓶颈，也没有被排除。 |
| **移除级联中间 teachers** | 邻近证据只有单 frozen B 的输出级融合 Dice；R1增量小、R5 V1独立分支有小幅 val 信号但传入冠军集成几乎为零。 | 没有多级 teacher、逐级 stage target、删除中间 teacher、featureKD 或 teacher detach 的消融。不能用 R1/R5 推导级联结构无用，也不能说中间目标必须保留。 |
| **取消在线 H4** | 固定底座上的 MA 后融合 H4 多次取得约+0.85至+0.98 pp test mIoU，非 MA 类不变；这是保留 MA 专项修正概念的正证据。HE 头失败只限制其类特异性。 | 历史没有在线共同更新主分支与 H4 的实验。旧头固定输入与在线分支输入分布不同，因此既不能把静态收益承诺给在线版，也不能把在线版直接取消归因于历史 H4 失败。 |
