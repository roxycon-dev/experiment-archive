# 实验报告：D 方案 20k 训练复跑（Student-Only 分支 Dice 监督）

## 1. 结论与当前进度

本轮完成了 D 方案（student-only 分支）20000 步的正式训练与 10 个验证点评估。最佳验证 mIoU 为 **41.62%（@2000 步）**，最终 20000 步为 40.48%。**本轮未进行测试集评估**：按预定门槛（验证集连续 2 次达到 42.4）未达标，故未触发 test 推理。因此，**本轮不能声称“在测试集上相对 baseline 提高 3 个百分点”**，正式目标 test 45.35 尚未达成，实验处于进行中而非完结状态。

需明确的边界：
- baseline val 39.39 / test 42.20 为历史报告数字，并非本轮复跑结果；
- 上一轮 test 42.35 属另一方案（previous ensemble），不是当前 D 方案结果；
- 当前 `current_test = null`，不产生任何 test 结论。

## 2. 方法与设置

- **数据划分**：train/val/test = 454/76/227，固定不变；本轮不重训 baseline。
- **D 分支配置**：仅 Dice 损失；BatchNorm 使用 running stats 并冻结，affine 参数可训练；采样策略为 50% 随机、50% 在图内阳性类上均匀选取中心。优化器 SGD，学习率 0.0005 余弦衰减至 0.00005，warmup 200 步。两路均以 B@3000 权重初始化。
- **推理（改进方向既定设置）**：真实高分辨率 HRNet 裁块 + 冻结 B 全局概率各 0.5 混合；1024 crop 来自 2048 原图，stride 768 保证覆盖；重叠区域 logits 取均值后回原图做 sigmoid；阈值 0.5，无 TTA。
- **损失修正**：原 Dice 实现中忽略 255 标签时未掩蔽预测，已修正。新增 Lovasz（权重 0.1）的 L 方案**仅完成准备，尚未启动训练**。
