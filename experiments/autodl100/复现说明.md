# 复现说明

最终方案为E4@36000与B@3000两个检查点的原图尺寸sigmoid概率固定等权平均，所有类别均使用0.5/0.5权重。验证39.54，测试42.35。方案和测试门槛在评估前记录于mean_ensemble_lock.json与mean_test_lock.json。早期按类别选择的方案测试41.82，已放弃，仅保留复核。固定sigmoid阈值0.5，无TTA，227张test，不含背景的四类累计IoU取均值。

代码在work/HRDecoder。使用与服务器一致的Python3.8、PyTorch2.0.1+cu117、mmcv1.7.1环境。将results/e4_reference_weights.pth放至代码根目录weights/e4_reference_weights.pth；将results/trial_b/selected_weights_only.pth放至weights/b_weights.pth。按bundle/split_assignment.json与data_manifest.json准备代码根目录data/DDR_split_613（454/76/227）。

在代码根目录执行：

```bash
PYTHONPATH=. python tools/test.py configs/lesion/exp/hr100_mean_release.py weights/b_weights.pth --eval mIoU
```

先载入E4参考模型，再由测试工具载入B主模型；载入B时提示缺少reference.*参数是因为B检查点不包含第二模型，第二模型已在构造时严格加载E4。不能忽略其他形状不匹配或主模型缺失警告。两份权重的本地SHA256及元数据见results/ensemble_weights_verified.json。

必须保持compute_aupr=True；旧仓库关闭它会改变simple_test返回格式，导致错误的样本累计。不要把输入类顺序更改成其他教程的标签映射，当前顺序为bg0/EX1/HE2/SE3/MA4。

AutoDL该镜像关机脚本需要由bash执行：/bin/bash /usr/bin/shutdown。每次开机前仍应在平台设置绝对关机时间；结束后从平台确认已关机。原先Python直接执行/usr/bin/shutdown发生Exec format error，不能再用该调用。
