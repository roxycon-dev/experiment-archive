# 新增训练之后的统一评估运行协议

2026-10-23，所有新增配对训练终点出现前冻结。此协议只补齐运行环境，不修改训练、推理几何、阈值或融合系数。

三组种子42、2024、3407均在各自20k EMA节点比较C/S。共同父模型和原32k学习率日程仍按additional_training_protocol.json。比较终点不可根据本次验证或测试分数改变。DDR test227及已冻结IDRiD27分别报告单模型和固定系统融合结果；这两个队列均逐图保存掩膜、整数TP/FP/FN及身份哈希，不增加数据集或阈值搜索。

为尽早并行完成推理，2080Ti服务器准备独立Python3.11环境，PyTorch2.7.1+cu118，所有六个C/S模型统一FP32前向、FP32 reference MSDA、禁用TF32，batch1、原图1024窗口/768中心/128halo拼接。Turing不使用本轮4080训练的BF16推理。现有种子42必须按同一协议重新推理，不能直接与早期BF16的42号结果混算均值和标准差。正式测试前固定validation图007-1774-100作形状、有限性、严格加载、几何、计数及资源检查；任何技术修复保留记录，不能按得分选择精度或后端。

共同旧系统P0=.75*A+.25*U。A为既定D/E/B/E4的3:2:1:1水平翻转集成及H4 MA修正；U为既定U0 native-whole。A/U使用已有legacy Python3.8、torch2.0.1+cu117、mmcv1.7.1，FP32；先固定validation哨兵再批量推理。每图共同P0只生成一次，六模型复用完全相同FP32概率文件及其SHA。固定系统始终计算(.75*P0+.25*model_probability)>.5，单模型始终model_probability>.5，严格大于，EX/HE/SE/MA顺序。

DDR的U重新在相同2080Ti legacy运行时计算；IDRiD U可复用已经完成并通过独立有限性/范围/SHA审计的4080 FP32缓存，避免重复native-whole前向，来源和硬件必须在P0逐图记录中保留。IDRiD不同几何及GT来源限制沿用external_protocol.md。A按同一legacy实现，在两队列重新生成，记录2080Ti运行身份与验证哨兵，不声称跨GPU逐位重放。早期阶段1四行结果继续独立保留，不用新的精度环境替换原始记录。

预测概率为float32，阈值不调。DDR在原图坐标按标签1/2/3/4计数、255忽略；IDRiD使用四份独立二值GT、保留跨类重叠。统计使用全图累计计数后算IoU，不平均每图IoU。三组分别报告S-C及其均值/样本标准差，说明只是同一父模型条件下的适配种子波动。图像bootstrap与种子方差分开。
