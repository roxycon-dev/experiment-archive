# 文献取舍与新方案依据

核查日期：2026-10-03。只把彩色眼底病灶分割的原始论文、作者代码和数据说明当作方法依据；分类、OCT层分割、真值提示的交互分割不直接作为本项目的增益证据。没有论文能把其公开划分的收益直接加到本项目的44.7809%。

|文献或资源|本次使用的证据|对方案的实际影响与限制|
|---|---|---|
|[HRDecoder，MICCAI 2024](https://arxiv.org/html/2411.03976v1)|原方法训练包含高分辨率表示学习监督，训练和推理使用高分辨率融合；HRDA是其重要参照。|H1只有普通学生前向的统一BCE+Dice，不能视作完整原方法复现。论文中HRDA与HRDecoder在官方DDR的mIoU接近，也提醒“增加局部编码”本身不是大幅提升的充分条件。|
|[HRDA，ECCV 2022](https://arxiv.org/abs/2204.13132)、[作者实现](https://github.com/lhoyer/HRDA)|真实高分辨率局部输入和低分辨率全局上下文互补。|支持分类前融合局部纹理与全局语义。本项目借鉴结构机制，不照搬域适应伪标签流程，也不引用其街景增益预测DDR收益。|
|[FixRes，NeurIPS 2019](https://papers.neurips.cc/paper_files/paper/2019/hash/d03a857a23b5285736c4d55e0bb067c8-Abstract.html)|训练与推理的对象尺度分布差异会影响模型；分辨率适配需要控制比较。|优先检查现有U0/U1权重的几何协议。研究原任务是分类，不能据此断言修正本项目的形变就能涨若干IoU。|
|[Group Normalization，ECCV 2018](https://www.ecva.net/papers/eccv_2018/papers_ECCV/papers/Yuxin_Wu_Group_Normalization_ECCV_2018_paper.pdf)|GN的归一化维度包含空间位置。|ConvNeXt编码器的LayerNorm不能代表其UNet解码器；解码器实际使用GN。整图与滑窗的区别不仅是边缘上下文，还包含空间统计，必须实测；不能把GN本身称为错误。|
|[M2MRF，Pattern Recognition 2023](https://www.sciencedirect.com/science/article/pii/S0031320322006707)、[预印本](https://arxiv.org/abs/2111.00193)|直接针对DDR/IDRiD微小病灶的特征重采样损失。|支持把真实浅层细节送入解码器；不支持只把低分辨率logits放大就称为细节恢复。先检验真实RGB跳连，再考虑替换一个重采样位置，暂不叠加模块。|
|[PointRend，CVPR 2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Kirillov_PointRend_Image_Segmentation_As_Rendering_CVPR_2020_paper.html)|细粒度特征与粗语义共同决定高分辨率预测。|支持特征级融合；本项目不采用只在不确定点修正的硬限制，因为高置信漏检可能没有进入不确定区域。原论文主要是自然图像。|
|[MAPLES-DR，Scientific Data 2024](https://www.nature.com/articles/s41597-024-03739-6)、[数据说明](https://liv4d.github.io/MAPLES-DR/en/welcome/dataset_description.html)|198图，其中官方train138/test60；标签包不含MESSIDOR图像；有不确定标注和明确的标注流程。|这是有价值的额外病灶/解剖监督来源，但本次没有配套图像，因此从未完成这条迁移路线。不能把所有新增标注视为同一粒度，不能把不确定区默认为阴性。|
|[IDRiD官方数据页](https://idrid.grand-challenge.org/Data/)|公开的病灶分割数据包含原图及对应像素标注。|本机使用的是用户预处理方形图与YOLO多边形衍生mask。首先补齐官方来源及坐标对应；当前衍生标注没有被证明错误，也没有被证明等同官方GT。|
|[Cross-Dataset Generalization For Retinal Lesions Segmentation，2024](https://arxiv.org/html/2405.08329v1)|跨数据集标注方式和域差异影响迁移，额外数据并非普遍改善。|外部数据降为资产齐备后的受控第二步；第一步不再将未知标签风格、结构与训练配方一起更换。|
|[RTNet，2022](https://arxiv.org/abs/2201.11037)|利用病灶与血管的软特征关系处理结构歧义。|若错误分层明确指向血管误报，可做后续软解剖先验；不能把MA只能出现在某个血管mask内写成硬规则，也不优先做“贴到血管上”的合成增强。|
|[WSRFNet，IJCAI 2024](https://www.ijcai.org/proceedings/2024/115)、[HACDR-Net，AAAI 2024](https://ojs.aaai.org/index.php/AAAI/article/view/28453)|两者均提出完整的病灶结构建模，而非一个孤立算子。|本轮随机初始化的HACDR骨干加项目解码器不能代表HACDR论文；旧Haar输入也不等于WSRFNet。保留研究价值，当前不优先重写整套网络。|
|[MS-SAM作者仓库](https://github.com/luoxingcheng7/MS-SAM)|2026-10-03查看仍只有README和待发布代码说明。|不能把未落地实现作为下一轮可靠主线。|
|[RetSAM，2026预印本](https://arxiv.org/html/2602.07012v1)、[作者仓库](https://github.com/Wzhjerry/RetSAM)、[公开模型卡](https://huggingface.co/JerryWzh/RetSAM_public)|论文使用DDR在内的公共影像；公开权重仅用公共数据，作者明确其与论文私有数据模型不同；公开病灶范围不含MA。|不是可直接兑现论文收益的捷径。未核清本项目val/test影像是否进入其训练，不能并入当前可比主实验；亦不能声称已经证明其泄漏了本项目某张图。若获得排除本项目留出集的权重/清单，才重新评估。|

筛选后的主线是“已经学到不同病灶表征的编码器，怎样在统一几何下把真实细节与全局语义结合起来”，不是“最新论文中哪个数字最大”。新近RetSAM值得关注，但发布权重、标签范围和训练来源的约束比标题里的foundation model更影响本项目是否能使用它。
