# HRDecoder 下一轮成熟方案：更换主要表征，分离验证真实监督的价值

日期：2026-10-03。状态：研究设计完成，尚未实施新训练；不是已验证的涨分配方。

## 决策摘要

**停止追加 M0/M1、旧残差头和融合比例搜索。主押独立的 DINOv3 ViT-B/16 四类病灶分割器，使用多层特征重建解码器与浅层空间支路；随后在同一架构上，配对检验官方 IDRiD 像素标注和 MAPLES-DR 的增益。**

重点不是再给旧 HRDecoder 增加一个注意力模块，而是让新的预训练表征承担主要识别任务，并允许它纠正旧模型共同漏掉的病灶。旧冠军作为固定的实际比较对象保留，不当作新模型的概率约束或伪标签老师。

当前有效部署 P0 的 test 为 **44.780891%**。目标沿用原冠军 44.2115% 加 3 个百分点，即 **47.2115%**，尚差 **2.430609 个百分点**。它是验收目标，不是根据论文增益推算出的承诺。现有证据足以改变押注方向，还不足以给出可信的达标概率。

本方案做两项有边界的投入：先验证新的表征体系，再检验新增真实监督。只设一个训练前的技术备选，不排列一串失败后无限追加的方法。

## 一、本次增加的证据，改变了什么判断

### 1. “只要把 M 的融合比例改回来”已不足以支撑续训

本次在本机 CPU 上读取已有的完整 76 张验证概率与标签，事先固定两个诊断配方，没有扫描权重，没有访问服务器，也没有重新读取测试集。用相同阈值和原坐标计数重算了 C、P0、M0、M1、H1，五组 TP/FP/FN 均与原始文件完全一致。

|验证候选|mIoU，%|相对 P0，百分点|配对图像 bootstrap 95% 区间，百分点|
|---|---:|---:|---:|
|P0：0.75 C + 0.25 历史 U0|43.48770|—|—|
|0.75 C + 0.25 M0@1000|43.52934|+0.04163|[−0.3531,+0.3767]|
|0.75 C + 0.25 M1@1000|43.50923|+0.02153|[−0.3883,+0.3691]|

因此，上一轮半融合降低冠军权重确实是设计不足，但修正它并没有显露出值得继续押注的明显收益。此处是事后验证诊断，不能改写上一轮冻结结果或宣布新冠军。两条区间也不包含历史选型和训练种子的全部不确定性。

### 2. 旧专家有互补，但大部分漏检是共享的

在 P0、C、M0、M1、H1 的阈值预测中，P0 漏检像素同时被其余所有专家漏检的比例为：

|类别|共同漏检 / P0 漏检|比例|
|---|---:|---:|
|EX|84,022 / 106,656|78.78%|
|HE|361,097 / 512,945|70.40%|
|SE|43,354 / 62,627|69.23%|
|MA|33,610 / 41,614|80.77%|

如果让真实标签逐像素指定哪个专家正确，理想选择器可以达到 val **60.3514%**。这说明不能断言旧专家“完全没有互补空间”；但这个选择器使用答案，不能部署，也不构成可实现增益或投入预算的依据。

这里的共同漏检按固定 0.5 阈值定义，不证明所有模型概率都极低，更不证明这些病灶不可识别。它与实测固定融合无明显增益合在一起，支持：**下一笔主要训练投入应增加可用信息和识别能力，不能只重新排列旧预测。**

### 3. 前几轮到底失败在哪里

- **小幅验证峰值被赋予了过高意义。** 最新 G 的 val +0.3802 点，test 却 −0.1464 点；测试差异区间含零，不能称确认退化，也不能称提升。76 张验证图被反复选型，孤立小峰很容易失真。
- **推理变化曾大于学习变化。** H1 同权重普通 forward 比旧 eval_forward 高 6.1091 点；U0 在 M 的零步几何下已比另一滑窗路径高 4.1817 点。M 学习后的额外单模增益只有约 0.27 点，不能把前面的几何差异写成新增架构贡献。
- **M1 的细节分支没有拿出效果。** 1000/2000 步分支投影已非零，梯度、冻结、坐标检查没有确认接线错误；不能继续用“没训练到这个模块”替负结果辩护。2000 步止损也不能被解释成所有类似架构均已收敛。
- **主要错误并非全部属于微小边界。** P0 的 HE/SE 漏检分别有 69.40%/72.24% 位于面积大于 1024 像素的 GT 连通域，且多数不在最外一圈。面积大于 1024 并不意味着超出 1024 窗口，因而不能据此证明必须获得整张眼底的长距离上下文；它支持优先查主体识别和覆盖，而非只增加轮廓细节。
- **过去的外部监督不能等同于充分的真实病灶预训练。** 本地只有 54 张 IDRiD 衍生方图及多边形版本，MAPLES 只有标签、没有配套原图。继续写“外部数据已试过，所以无用”会过度外推。

分支关闭实验仍可作为 M 的机制补充，但不再是新路线开工前必须花 GPU 完成的关卡。完整原始复核见上一轮的《结果复核与决策修订》。

## 二、主架构：让新表征直接负责病灶识别

### 选择及文献依据

主编码器选 **DINOv3 ViT-B/16，LVD 预训练权重**。选择理由是已有可获取的官方权重、可直接提取稠密特征、规模允许尝试单张 24GB GPU，而不是名字更新。其通用稠密预测证据支持把它列为候选，**并不证明在 DDR 上优于 HRDecoder，更不提供 +3 点的效应量**。[DINOv3 论文](https://arxiv.org/abs/2508.10104)、[官方权重与实现](https://github.com/facebookresearch/dinov3)

采用 DPT 式多层特征重建与逐级融合，是为了把 ViT 的粗空间网格恢复成像素预测；不用文本提示，不加载不相干的 ADE20K 类别头。[DPT 原论文](https://arxiv.org/abs/2103.13413)

```text
原生 RGB 1024×1024 窗口
  ├─ DINOv3-B/16 → 第3/6/9/12层特征 → DPT式尺度重建与逐级融合 ─┐
  └─ 轻量 RGB 卷积空间支路 → stride 2、stride 4 特征 ──────────┤
                                                        四类独立 logits
                                      只对中央768×768真实有效像素监督/拼接
```

具体接口和空间账本写在《02_执行与验收规范》。四个 ViT 层的原始特征**都是 stride 16**；必须显式重建 stride 4/8/16/32，不能把“取四层”误写成天然四尺度。空间支路保留局部定位信息，不宣称它本身是创新或一定涨分。

这与 M1 有实质区别：M1 给已有卷积 U-Net 再加细节；这里浅层支路负责补充新 ViT 主干的粗网格。M1 的失败降低了对“再加细节”的期待，却不能直接否定这种基础解码设计。反过来，若新模型获益，仍要消融才能把增益归给空间支路。

### 与现有 HRDecoder 的关系

新模型暂称 **Q**。直接复用已验收的划分、原坐标计数、1024/768/128 窗口账本和结果归档；更换完整主要表征与解码部分。不把 D 的 64 通道压缩特征继续塞给 U0，不依赖旧模型的高置信区域或候选掩膜，不限制新模型翻转旧模型的阴性预测。

这是一个新的病灶分割系统，不宜仅换名字称“HRDecoder 的一个小模块”。如果最终用 Q 单模就能接近或超过复杂 P0，将同时获得性能和部署简化；若必须融合，如实报告多模型成本。

1024 窗口内的 ViT 注意力提供窗口内上下文，**不等于整张眼底全局建模**。目前没有证据证明视盘到黄斑的整图关系才是主因，所以本轮不同时叠加全图塔、位置路由和新损失。完整眼底上下文仅在新模型错误审计证实有需要后再提出新实验。

### 唯一技术备选

若在正式训练前，ViT-B 的真实末四层反传在 24GB 上无法通过显存/时间验收，改为 **DINOv3 ConvNeXt-Small + 同级轻量多尺度解码器**，重新冻结配置再开始。它是资源适配备选，不与主线同时大规模搜索。原 U0 也是 ConvNeXt-Small 家族，因此这个备选的主要新信息来自预训练，而非把同一骨干换名。

ViT 正式结果不好后，不自动启动这个备选来无限续费。届时需判断是微小病灶空间表现、语义域差异还是普通过拟合，再决定新实验。

## 三、真实监督：作为第二个可分辨的问题

准备 **官方 IDRiD 54 张训练原图及像素标签 + MAPLES 138 张训练原图及标签**。IDRiD 的 54 张与旧衍生资产是同一批病例，不是新增 54 个独立患者；其价值是标签与几何质量。MAPLES 才提供最多 138 张新的图像，且需先完成跨数据集去重。[IDRiD 官方数据说明](https://idrid.grand-challenge.org/Data/)、[MAPLES 数据说明](https://liv4d.github.io/MAPLES-DR/en/welcome/dataset_description.html)

当前 MAPLES 原图并未齐备，必须从 **MESSIDOR-1** 按 ID 配对，不能拿 MESSIDOR-2 代替。官方获取涉及用途和个人下载链接；本次没有代填申请、提交个人信息或假称已经下载。[MAPLES 配图说明](https://liv4d.github.io/MAPLES-DR/en/welcome/messidor.html)、[MESSIDOR 官方入口](https://www.adcis.net/en/third-party/messidor/)

外部源保留原图比例与原生窗口。本轮不新增按疾病“体积”调阈值、不把 MA 粘到预测血管上。不同相机像素尺度确有域差，需报告；先用来源均衡和末段 DDR 适配处理，不通过验证集再挑一套缩放。

|实验|前12000次更新|最后4000次更新|回答的问题|
|---|---|---|---|
|Q_DDR|仅 DDR train|仅 DDR train|新的完整表征/解码体系能否胜过当前实际部署？|
|Q_MIX|每有效批 DDR 4 窗口、外部4窗口|仅 DDR train|固定总计算与架构下，把部分训练暴露换成真实外部监督是否有用？|

外部四个窗口来源按每批 IDRiD 2、MAPLES 2 固定。Q_MIX从第12001步起全部使用DDR；若延长到24000步，增加的8000步也全部使用DDR，不恢复外部混合。两组初始化、种子、总更新数、有效 batch、几何、损失、学习率日程一致；可复用相同 DDR 抽样序列的对应部分。

**相同更新数不等于相同 DDR 暴露。** 16000 步时 Q_DDR 看 128000 个 DDR 窗口，Q_MIX 看 80000 个 DDR 窗口和 48000 个外部窗口。该配对估计的是等计算预算下的监督分配收益，不是“额外数据在相同 DDR 暴露下”的纯效应。

只获得旧 54 张的官方版本而未取得 MAPLES 时，不把上述 Q_MIX 偷换成不同配方。先完成 Q_DDR；若另测标签质量，应另记小型独立实验。FGADR 有 1842 张分割样本，但当前需要签研究协议并申请，尚未拿到数据；不把它写进必然可执行的主预算。[FGADR 官方获取规则](https://csyizhou.github.io/FGADR/)

跨数据集研究显示标签粗细与来源会影响迁移，加入 FGADR 并不在所有目标数据集上稳定更好。这正是设置 Q_DDR/Q_MIX 配对和末段 DDR 适配的理由，而不是宣称“更多数据必涨”。[Cross-Dataset Generalization for Retinal Lesions Segmentation](https://arxiv.org/html/2405.08329v1)

## 四、训练给足机会，但不无限续训

### 固定基础配方

- 454/76/227 不变。新模型不从旧 D/U0/M 权重续训；编码器从审查后的 DINOv3 权重开始，解码器新初始化。
- 有效 batch 8，计划 micro-batch 2、累积 4；训练前若显存不够，统一改为 micro 1、累积 8。正式组间保持相同设置。Dice 使两种微批拆分并非数学等价，不能中途偷偷替换。
- 前 2000 次更新只训练解码器与空间支路；随后只解冻 ViT 最后四层及最终归一化。新 head 不用 1000/2000 步的弱成绩直接判死刑。
- AdamW：head 初始 3e-4，解冻主干初始 5e-6，weight decay 0.01，梯度裁剪 1.0；warmup、参数分组及精确日程见规范。只用固定的四类 masked BCE + Dice，不叠加 Lovasz、Focal、边界和蒸馏损失。
- 基础观察长度 **16000 次优化器更新**。只做一条预注册的收敛延长：若任一已完成发现臂的单模 val 在 12000→16000 步仍提高至少 0.3 点，则两臂统一延至 24000；调度器从开始就按 24000 定义，延长不重置学习率。复核种子沿用已决定的共同终点。资源不足则记为未完成延长，不把某一短臂叫作公平最终对照。
- 完整 val 节点为 2000/4000/8000/12000/16000，扩展时增加20000/24000。曲线用于诊断，正式候选只取12000及之后实际共同完成的节点。

16000/24000 是投入边界，不是收敛定理。0.3 点延长条件是预先声明的成本决策，不是统计显著性。若在 24000 仍明显上升，报告“预算边界处仍未收敛”，不能擅自再开一轮。

### 真正的止损条件

非有限数、标签/坐标错误、预训练加载遗漏、冻结失效、断点身份错误属于立即暂停的技术问题，先保存证据再修复，不盲目重启。

在没有技术错误的前提下，**不在 8000 步前因落后复杂旧集成而停止**。到 8000 步，只有以下条件同时成立，才允许提前结束整个架构试验：单模 val 低于 35%，固定25%融合比 P0 低超过1点，并且单模从4000到8000提升不足0.2点。此为严重失败筛查，不是预判一般学习曲线的工具；触发后也不把它归因成某个模块已被严格证伪。

其余情况完成既定长度。不要只因为训练 loss 下降就续费，也不要只因一次 val 回落就改损失或采样。

## 五、选型、重复与真正的达标标准

### 执行顺序

1. 本机完成预训练权重、真实监督和坐标/指标验收，冻结运行清单；再使用一台 24GB GPU 测完整前反传和一次完整 val 耗时。
2. 跑 Q_DDR 的 seed 42 发现试验。若未触发严重失败规则，完成16k及适用的共同延长。其作用是检验新体系能否学习，不假装已单独测出编码器贡献。
3. 数据完整时跑 Q_MIX seed 42；架构与优化器配方不变。若触发延长规则，补齐另一臂共同长度。
4. 若任一配方的两个相邻正式晚期节点均达到 P0 +0.5 点以上，购买一次 seed 2024 的配对复核：有 Q_MIX 时两臂都重复；否则仅复核 Q_DDR。该门槛只决定继续投入，不表示达标或显著。
5. 若发现阶段没有这样的信号，结束本方案的自动追加；完整报告结果，不转去搜索更多阈值、更多种子或更大模型。若两个种子分歧，证据不足，不选择性删除差的种子。

### 固定候选，避免重复上一轮的峰值选型

每个正式节点只允许 **Q 单模** 与 **0.75 P0 + 0.25 Q** 两种部署配方，P0 固定不变。这里的 P0 本身已含 C/U0，必须记录完整展开式；它与本次 CPU 诊断用的0.75 C +0.25 M不是同一配方。二者都有目的：单模允许充分改变旧模型错误，低比例融合检验保守部署收益。

发现阶段的“两相邻节点”必须来自同一训练配方、同一种部署公式，不能一个节点挑单模、下一个挑融合拼成持续改善。

两种子完成后，用共同晚期节点的**两种子平均 val mIoU**一次性锁定训练配方、节点和部署公式；并列取更早节点，再并列优先单模。报告全部试过的候选数量。主要科学比较 Q_MIX−Q_DDR 明确为**同一最终更新数的单模对单模、配对种子比较**，不混入P0，不用各自最优节点，避免融合和选点混淆监督效应。

只有两种子方向一致且锁定候选平均仍高于 P0 至少0.5点，才进入一次集中的最终 test；完整报告两个种子的 test，不看 test 决定用哪个模型。预先指定 seed42 为复现部署身份，同时报告两种子平均和范围。本轮不自动增加跨种子集成、类别挑选或第三种子寻优。

**达标的严格说法：**两个预指定种子的固定配方分别达到test47.2115%，才能写“已在两个种子复现目标”；同时披露平均、范围和图像抽样区间。若仅平均达到而某个种子未达到，写“均值达标，尚未逐种子复现”；若仅一个种子达到而平均未达，写“单次达到，整体未达标”。两次成功仍不是未来运行必达的保证。如果只有含 P0 的融合达标，称系统/集成达标，不能写成 Q 单模型或一个新增模块提升3点。

图像配对 bootstrap 使用逐图 TP/FP/FN 重采样后重新聚合四类 IoU；不能对像素独立采样，也不能把图像区间当作种子方差。检查收益是否由少数图像或一个类别支撑，公布每类变化而非事后调整门槛。连续的 val +0.5 仍可能不泛化，这一风险不因重复两次就消失。

### 数据划分的诚实边界

旧权重已经见过全部454张训练图，把它们重切出一个内部验证集不能洗成独立确认集。当前76张val、227张test都经历过历史使用，本轮最终结果仍属探索性延续；冻结新规则只能减少新增选择偏差。

若需要论文级外部确认，先核实 IDRiD 官方27张、MAPLES官方60张在整个历史中是否未用于训练和选型，再在主方案锁定后作独立外部评估；结果与DDR分开，不能挑表现更好的外域替代DDR目标。无法证明未使用时，如实标记，需新的独立患者数据。

## 六、为什么删掉其他看起来诱人的方向

## 最终判断

我最看好的是“新的主要表征 + 经核实的真实监督”，而不是继续微调旧预测。信心来自对旧路线失败原因的排除、权重和接口的可执行性、以及可以分别检验两种新信息来源；**不是已经有DDR涨分实证**。

最可能的失败原因依次是：通用预训练对病灶语义迁移有限、真实外部数据太少或标注风格冲突、ViT粗空间特征使MA代价抵消HE/SE收益，以及反复使用的小验证集继续产生乐观选型。方案分别用有限层适配、监督配对、空间支路与逐类审查、两种子及冻结候选去检验这些问题。

突破应该体现为固定配方在重复训练和完整测试上的稳定提升。完成本方案后，要么得到这样的模型，要么明确判定这笔主要投入没有达到目标；不会继续用新的小峰、新口径或追加未经审查的模块包装成成功。
