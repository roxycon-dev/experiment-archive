# 独立反方复核：NativePyramid-SP v3（2026-10-16）

## 裁决

这是一个可检验的单模型假设，不是已获历史支持的达标结构。四尺度直接线性读出改变了特征到logit的梯度路径；它不是把此前缺席的多尺度信息加进来，也没有历史证据证明能超过产品融合。v3可以作为候选继续评审，但历史审计不支持把其成功概率、稳定性或目标分数写成既定事实。

历史证据能说清的核心限制是：纯W48最佳报告值仍是B0的test 42.20%，而候选目标val/test来自累计训练、异构模型的融合系统。B0与融合目标不是匹配比较，B0的测试计数和原权重身份缺失。ArchitectureDesign的CET完成40k但最高val 40.4876%、末节点38.3138%；其它候选多为短screen或在约20k前停下。没有任何候选给出“同一ImageNet W48、相同454/76/227、global batch 2、40k、候选推理图”的目标级结果。

## 目标差距和类错误要分开读

B0报告的best-val为39.390%@32k、test为42.20%，融合目标为val45.321831%、test45.860384%，表面差距分别是5.932和3.660个百分点。B0报告另给四类test IoU（EX51.56、HE43.13、SE49.98、MA24.11），但只舍入到两位，且没有B0逐类TP/FP/FN。因此不能精确分解“同一W48还差多少漏检或误报”。B0计划40k但test使用best-val@32k模型；v3若以raw@40k为主结果，报告应并列说明选点差异。固定test也已经在历史决策中复用，不能描述成新盲测。

最终融合对P0的精确count差更能说明产品融合的增量由哪些类贡献，但它仍不是W48因果证据：

|类别|P0 TP/FP/FN|最终融合 TP/FP/FN|IoU变化|
|---|---:|---:|---:|
|EX|1,072,861 / 390,087 / 502,080|1,084,309 / 392,193 / 490,632|+0.524 pp|
|HE|1,609,384 / 506,944 / 1,444,094|1,623,523 / 460,808 / 1,429,955|+0.996 pp|
|SE|354,891 / 138,077 / 215,627|363,816 / 117,499 / 206,702|+2.795 pp|
|MA|80,222 / 84,314 / 109,821|78,485 / 78,341 / 111,558|+0.0035 pp|

相对P0，SE、HE主要通过少一些FP和FN、同时增加/维持TP取得增量；MA的TP略降、FP下降、FN略升，IoU几乎不变。对B0报告的四舍五入IoU作描述性比较，最终融合的MA差距反而最大（约+5.13 pp），而最终融合相对P0的边际收益主要在SE、HE。两种比较的参照不同，不能混为“W48主要缺MA”或“必须增加细节支路”。

目前最有针对性的正向历史机制是H4：冻住D+reference底座，只训练约2k的3361参数MA校正头；test MA从24.7290到28.1383，MA TP/FP/FN从69,270/90,073/120,773变为80,641/96,545/109,402，其它三类计数逐项不变。它支持“固定底座上的窄MA纠错可换来更高MA IoU且增加FP”，但不是W48主干更新，也不是单模型40k证据，test已被使用。

v3删除裸RGB支路是合理的复杂度取舍，但没有被证明为“删掉有害输入”。短screen中adapter 4k为30.444、同节点base 26.808，而semantic为32.889、base 33.255；多个试验的读出、监督、detach与教师同时变化，不能分离出RGB单独贡献。新方案仍通过预训练stem读取RGB。去掉显式裸RGB可能减少捷径风险，也可能丢掉局部色彩/纹理补充，现有运行不能判断方向。

## 对v2继承与改动的具体意见

**没有被历史证伪的部分：** v2保留完整深层语义、单个W48端到端监督、2048输入、按完整batch定义的损失分母、训练/评估几何分开核验，以及类别级PAUSED监控。这些能减少已知工程错误或暴露崩塌；没有证据它们单独能把mIoU推到目标。v1的128-step学习检查没通过，不能以v1验收替代v2或v3验收。

**没有被历史验证的核心部分：** 逐级64通道瓶颈是否是目标主要限制；四尺度直接线性求和是否会改善HE/SE；预训练stem加PixelShuffle残差是否比B0 head有效；channel-LN是否胜过GN；固定BN及OHEM组合是否稳定；相同40k下是否跨过融合门槛。每项都是待验证假设。

**可能重演的风险：** 继续保留零初始化细节末层、GN/LN之外主干固定BN、W48/2048输入与原global clip及困难负例损失，仍和发生过类别消失的环境有重合。它们不是失败证明；但设计稿不能把“新直达语义路径”写成已保证替换了这些风险。线性分支可能出现尺度间logit幅度不匹配或梯度相互抵消；S与Z共用S并各受损失监督，改变了骨干梯度总量。主训练每步样本数相同，不代表FLOPs/显存/墙钟开销与B0相同；请把公平边界称为相同update/image budget。

## 对设计稿的阻断性修订建议

1. 继续把v3标成假设，性能门槛必须经过新训练与固定val/选择/test协议；明确最终目标是异构融合参考，不能把对融合的差值说成同结构、同预算胜负。
2. 保留B0作为唯一历史纯W48强参照，但在表中写清test选用32k最佳val，计划/上限40k；逐类TP/FP/FN、原checkpoint身份缺失。不要以舍入的B0报告数补造计数。
3. Detail的4k比较现已由原始`detail_execution/validation_series.json`核实：注明它比较同一checkpoint的private/base head，并列出MA的TP下降3,435、FN增加3,435、FP下降1,263,618；不要称成独立训练基线或高分辨率单变量因果。对“HE/SE大病灶内部漏检”同理：运行计数是全图累计，没有空间分区字段，需注明其它已有来源或降为假设。
4. 把“损失保持v2”限定为公式/系数相同：S成为辅助监督对象、direct classifier多路径回传后，梯度图已经改变；不得承诺只改变结构。
5. 对线性分支记录每尺度、每类logit贡献和梯度；对C/D区分末层首步与内部后续步；普通SGD记录global-clip前后各模块梯度份额。把这些作为解释信号，不把相关曲线升级为单变量因果。
6. 把channel-LN的承诺限制为“每个归一化算子不跨空间统计”；不声称整个网络padding不变。固定BN为待试设置，不描述成解决已证根因。2048应写输入画布和更新预算，不叫传感器原生分辨率。

## 最后复审收口

**文档层问题已修正/有证据可修正：** 本审查现引用Detail 4k原始validation-series节点，明确private/base是同checkpoint双头比较，并按TP/FP/FN说明MA IoU提升主要来自FP下降、伴随TP与recall降低；它不是独立训练对照。当前主稿已把病灶内区解释从实测结论中移除，并明确channel-LN为算子级性质、零残差不是性能保证、S/Z双监督改变了梯度图、相同40k更新不代表相同FLOPs。覆盖记录也已更新为我方30/30全文，整体59份完整正文+1份物理截断文件、0份未读。

**仍缺的是未来实验/源证据，不是本轮文档未完成：** NativePyramid-SP v3没有运行结果；四尺度线性分类是否提高HE/SE、末层更新后内部梯度能否恢复、尺度间是否抵消、不同norm和loss对40k终点的影响，以及超过融合门槛的可能性，都不能由历史表格回答。aggregate TP/FP/FN也无法判定病灶内部与边界的空间差异。根代理已计划补逐尺度logit/梯度及global-clip前后模块贡献记录；这些只能在未来实现/训练时验证，不能作为本轮历史审查已证明的性能结论。
