## 第一轮：从历史证据反查结构

重新核对了原HRDecoder segmentor、FCNHead、W48继承配置、DDR配置、当前data.py，以及历次运行审计。核对结果是：原方法的全图路径先在较粗特征网格上完成非线性解码，再上采样；局部特征裁块又提供另一种解码尺度。仅保留“两个输入尺度”和“M4辅助项”，不等于保留了这种解码尺度分工。

## 第二轮：找出r3的具体遗漏并修正

r3先将G的64×256×256投影结果插值到512，再用7×7核解码。这样两路空间核都在512网格上工作；G编码器仍有较大的输入支持范围，但G解码器不再在原256网格上读取7×7邻域。

这不是名称问题。令U为两倍线性上采样、K为7点均值卷积，在32点输入的第13点放置单位脉冲，观察64点输出的第32点：

~~~text
K(U(x))[32] = 0
U(K(x))[32] = 1/7
~~~

反例避开边界，说明先上采样已经改变这个空间算子的依赖范围。它是一维固定算子检查，不是准确率实验，也不意味着W48整体缺少全局信息。

因此r4固定为：

~~~text
G: W48(1024) → 拼接720 → P_G/BN/ReLU → K_G(7×7)/BN/ReLU → 上采样512
N: W48(2048) → 拼接720 → P_N/BN/ReLU → K_N(7×7)/BN/ReLU → 保持512
H: concat(N,G) → M(1×1,128→64)/ReLU → 共享分类器64→4 → 上采样2048
~~~

两个W48调用共享一份主干。P_G/P_N独立，K_G/K_N独立；G空间读出的采样间距为画布8像素，N为4像素。没有新增第三条表示塔。联合层M只有8,192参数，无bias、无BN；最终仍是一份四通道预测。

每路先完成非线性解码，可以在联合判断前保留各自尺度的特征响应。其代价是改变了r3的非线性位置；不能同时宣称“新结构严格包含r3所有函数”。保留r3的独立通道投影思路，不继承r3其他数学结论。

### 初始化避免增加额外的启动障碍

两路P/K各自独立，但复制相同初值；新增BN各自建域。分类器共享，随机非零初始化。M的初值固定为[I/2,I/2]，没有全零门：

~~~text
N,G ≥ 0
ReLU(M[N;G]) = (N+G)/2
C((N+G)/2) = [C(N)+C(G)]/2
~~~

所以初始联合输出与两支路在512网格上的logit均值一致，两路对主损失的局部导数均含非零1/2系数。之后M通过GT学习通道组合，不能把后续预测描述为固定均值。这里没有声称两支路一开始就具有病灶语义。

以真实通道数720/64/4、缩小的空间网格运行[解码器参考定义](D:/dataset/experiment/HRDecoder_NativePyramid_20261011/review_20261018/r4_decoder_reference.py)，初始等式最大绝对误差为1.3411×10⁻⁷。独立参数不共享可写存储，初始化保持调用者RNG状态；M、两路P/K及分类器在该合成主损失检查中均获得有限非零梯度。该观察只证明所测输入下路径接通，不证明训练指标。

### M4的作用域重新明确

M4从G的720通道主干特征裁块并缩放到256，沿P_G、K_G及同一分类器输出，直接监督G解码器。它不经过P_N、K_N、M，因此不会直接更新这些参数。参考计算图逐参数核对了这一点。

M4仍会通过G更新共享W48及共享分类器，因而仍会间接改变N输出；不能称为两个完全独立的模型。M4的随机范围、四框、有效实例过滤、0.1系数及平方Dice保持不变。没有额外N辅助损失，没有新损失权重需要用最后一次训练调节。

## 第三轮：尝试推翻新结构的假设

|反问|审查结论|
|---|---|
|只是把同一个算子改写了一遍吗？|不是；空间脉冲反例确认G的解码/插值顺序改变了依赖范围|
|能从参数增加推出5.90pp提升吗？|不能；增加8,320个参数只描述容量成本，不产生指标下界|
|能保证恢复B0函数吗？|不能；B0裁块融合与本模型不同，串联插值也不等于一次插值|
|M初始化平均会使一路学不到吗？|没有结构性的零门；两路都有主损失通路，但具体神经元可以因ReLU或梯度抵消而不更新|
|两个尺度一定互补吗？|同一W48可能学到相关特征；保留独立解码提供使用尺度差异的能力，不把互补当成已测事实|
|分支独立是否意味着没有梯度竞争？|仅独立P/K；共享W48和分类器仍接收合并梯度，global clip也会耦合各部分|
|增加更强注意力或类特定头是否更稳？|没有本任务匹配证据支持；本次不再加新塔、原型注意力、RGB头或额外class head|
|限制logit幅值是否能保证不崩塌？|不能；全部输出−1仍可导致整类零检出，因此不靠任意tanh/硬截断制造稳定保证|
|简单恢复融合系统作为兜底可以达标吗？|不符合本任务单W48、同预训练起点的设计比较，也不构成严格超越；未采用|
|同40k是否等于同计算量？|两次编码加重算显著增加计算；只保证同更新、同原图batch和同预训练，不声称同FLOPs|

串联插值的反例已记录：同一单位脉冲先×2再×4，与直接×8的最大绝对差为0.1875。故文件没有保留“初始输出等同B0”的错误承诺。

BN分域同样核查：P_G和K_G各自有G/aux统计域、内部共享affine；P_N与K_N各有独立N域和affine；M后无BN。合成检查中，跳过全无效aux后只增加G/N计数，不增加aux计数。实际W48的物理batch2和重算状态仍须由完整实现核对。
