# HRDecoder-JointContext：最终架构方案

初稿2026-10-17，**2026-10-18主代理架构专项复审，版本r3**。本文件为当前统一设计，取代05及JointContext v1/v2；完整模型尚未实现、尚未训练。这里的r3是JointContext设计修订号，与已训练失败的NativePyramid v3不是同一架构。10月17日原稿保存在[首次修订前快照](D:/dataset/experiment/HRDecoder_NativePyramid_20261011/review_20261018/before_revision/07_HRDecoder_JointContext_最终架构方案_20261017.md)，本次修改前的v2保存在[架构专项修订前快照](D:/dataset/experiment/HRDecoder_NativePyramid_20261011/review_20261018/before_r3/07_HRDecoder_JointContext_最终架构方案_20261017.md)。本轮不消耗正式训练机会。目录中的model.py、train.py和protocol.json仍对应已完成的NativePyramid v3，不能直接作为本方案的执行入口。

最终选择：**一个共享ImageNet HRNet-W48，处理1024与2048两个尺度；两路分别使用独立可训练的720→64投影P_G、P_N，再形成正交归一的共同/差异特征，由一个非线性分类头作最终判断。主损失汇总同一步两张图的统计量，所有类别均使用同一平方Dice公式。** 保留原HRDecoder的M4特征裁块辅助监督，与G路径共享P_G。两个投影初值相同、参数独立，解除v2强制共用通道子空间的限制。保留v2对空类BCE、BN和autocast缓存的修正。

固定条件：同一预训练文件、同一融合标签、40,000次SGD更新、每次2张原图，目标为固定40k权重的val mIoU严格超过45.32183122738841%，再按既有协议评估test是否超过45.860383832668%。当前机器规格见[jointcontext_spec_r3.json](D:/dataset/experiment/HRDecoder_NativePyramid_20261011/review_20261018/jointcontext_spec_r3.json)。本次架构推导与证据边界见[09架构专项审查与修订](D:/dataset/experiment/HRDecoder_NativePyramid_20261011/09_架构专项审查与修订_20261018.md)；[08复审记录](D:/dataset/experiment/HRDecoder_NativePyramid_20261011/08_主代理反复审查与修正_20261018.md)保留为v2的历史记录。

## 1. 这次修正针对什么

主代理已重新汇总v3和融合目标各76张验证图的逐类TP/FP/FN，并核对SID和每图每类GT总数一致。v3固定40k的val为39.425551%，与目标相差5.896280个百分点。

|类别|v3 40k IoU|融合目标IoU|目标TP−v3 TP|目标FP−v3 FP|
|---|---:|---:|---:|---:|
|EX|46.621127%|50.370204%|−4,420|−39,153|
|HE|40.943980%|45.040467%|+3,547|−145,776|
|SE|49.639041%|59.841784%|+14,210|−19,544|
|MA|20.498056%|26.034870%|+3,833|−8,583|

关键约束是：**即使清零所有“无该病灶图”上的该类FP，同时保持有病灶图的预测不变，mIoU也仅为41.273504%。** 因此方案必须同时面向有病灶图中的定位、漏检和误检，不能只修空阳性损失。该数字是已有计数的条件计算，不是新模型成绩。

完整40k日志投影显示首/末2k平均loss为1.147201/0.450293；SE无阳性更新占49.175%，MA占7.1275%；梯度裁剪触发26.77%。这些数据支持检查监督与读出方式，不支持把失败简单归因为“梯度为零”“训练完全崩塌”或“裁剪必然有害”。证据和范围见[主代理独立复算](D:/dataset/experiment/HRDecoder_NativePyramid_20261011/review_20261017/root_independent_audit.json)。

相对05及后续复审稿，当前保留以下修正：

1. 用共同特征、差异特征和联合非线性读出，替换05的固定双路logit平均。上下文在分类前参与细节解释。
2. 主损失先合并两张图的统计量，再求每类Dice；撤回会在空类与稀疏阳性之间大幅切换梯度量级的单位权重BCE。
3. 明确双尺度BN、M4有效裁块、autocast缓存边界及完整主干反传；用小型CPU计算图对照完整反传与分段反传，检查梯度和状态是否一致。
4. 本次r3新增：把共用投影拆成P_G、P_N，卷积和BN affine分别可训练；P_G只与M4共享。这样两种尺度不再被迫选择相同的64维通道子空间。前述CPU对照对应v2，不是拆分后的r3运行验收。

架构依据同时收紧：W48一条深层卷积路径的名义感受野已达2783像素，增加G不能解释为“原模型没有全局感受野”。G提供不同的物体表观尺度与特征响应；是否带来实际互补仍取决于所学特征。融合目标还包含异构模型、翻转TTA及任务训练链，双尺度W48不等同于复现这些能力。完整来源和推导见09。

历史负结果也约束了选择：CE+Dice的历史test约39.43%，低于对应B0约42.20%；此前IoU纠错配方在4k筛查中出现SE误检大幅下降但TP同步锐减。这些实验含有其他差异，不能证明某种损失普遍无效，但足以排除“直接加强BCE/Lovász就必然提升”的依据。本方案没有采用全像素CE+Dice、Lovász、正负组均衡BCE或OHEM。相关原始记录见[历史诊断](D:/dataset/experiment/HRDecoder_诊断调研_20260910/HRDecoder_诊断与押注建议.md)和[IoU纠错趋势](D:/dataset/experiment/HRDecoder_ArchitectureDesign_20261008/iou_execution/趋势分析记录.md)。

## 2. 唯一主路径与张量尺寸

每步两张图经过一次既有增强，得到X∈R^(2×3×2048×2048)。从同一X构造G视图U1024(X)与N视图X，不能分别重新采样增强。

|位置|G：1024输入|N：2048输入|
|---|---|---|
|W48第1分支|48×256×256|48×512×512|
|第2分支|96×128×128|96×256×256|
|第3分支|192×64×64|192×128×128|
|第4分支|384×32×32|384×64×64|
|对齐到本视图第1分支并拼接|FG720：720×256×256|FN720：720×512×512|
|独立投影P_G / P_N|64×256×256|64×512×512|
|投影后对齐|G：64×512×512|N：64×512×512|

表中省略batch维。主干是一份共享参数，不是两份独立可训练W48。主干内部31处多尺度融合上采样统一为bilinear、align_corners=False。本文所有双线性插值均使用align_corners=False、antialias=False。

这里的“对齐”表示采用明确的张量采样约定，不声称两尺度的物理感受野中心逐点相同。复审发现，按原始stem中心构造的坐标斜坡与常规插值存在1.5输入像素的相位差；真实多分支语义特征不是坐标斜坡，现有证据不足以支持额外grid_sample校正，所以保留既有插值规则。

投影及主头严格定义为：

~~~text
P_G(F; domain) = ReLU(BN_G_domain(Conv1x1(F, W_G)))  # domain=G或aux
P_N(F)        = ReLU(BN_N(Conv1x1(F, W_N)))
G = U512(P_G(FG720))
N = P_N(FN720)

C = (N + G) / sqrt(2)
D = (N - G) / sqrt(2)
A = Conv7x7(C, Kc) + Conv7x7(D, Kd)
H = ReLU(BN_main(A))
z512 = Conv1x1_64→4(H)
Z = U2048(z512)
~~~

两组7×7卷积均为64→64、padding=3、dilation=1、无bias；投影卷积无bias，最终四类分类器有bias。没有额外ASPP、浅层RGB预测、PixelShuffle、自由logit残差、标量门控或dropout。**最终只有一个四通道预测Z。**

W_G与W_N均为64×720，但不是同一个Parameter；两个投影的BN affine也独立。P_G内部的G/aux两域共享卷积和affine、分开running统计。后续讨论中的N、G指投影后的64通道特征。

共同/差异表示正交归一：N=(C+D)/√2，G=(C−D)/√2，且||C||²+||D||²=||N||²+||G||²。它保留两路已经投影的64通道信息及欧氏能量，不能找回720→64投影已经丢弃的信息。并且：

~~~text
Conv(C,Kc) + Conv(D,Kd)
  = Conv(N,(Kc+Kd)/sqrt(2)) + Conv(G,(Kc-Kd)/sqrt(2))
~~~

它等价于对两路特征拼接后的可学习卷积，而不固定两路最终预测的权重。Kd=Kc时主头卷积只读取N；Kd=−Kc时只读取G。一般情况下可利用二者的不同通道和邻域信息，再经过BN/ReLU完成联合分类。这是表达能力上的事实，不表示优化过程必然找到最优组合，也不表示完整模型严格包含历史B0全部预测过程。

v1采用除以2的可逆变换，却没有区分函数等价与优化坐标等价。现在除以√2，核坐标与梯度范数同样保持正交；SGD、动量、各向同性weight decay及global norm clip在相应坐标变换下相容。BN会消去大部分共同尺度变化，因此不将该修正宣称为实际学习速度翻倍或已证mIoU增益。

r3对v2的包含关系有明确构造：令W_N=W_G、两个投影affine相同，并对应复制原G/N/aux缓冲区，其余参数不变，即可复现v2的预测函数。拆分后允许两种尺度选择不同通道组合。该关系只涉及可表达的预测函数；共享W48、每路64通道压缩及最终64通道读出仍然存在，不构成对融合模型函数族的包含证明。

## 3. 初始化与首步梯度

W48只加载指定ImageNet预训练权重，逐键核对1,830个主干张量，明确排除126个分类张量；不使用B0、v3、融合模型或其他病灶任务训练权重。

新头初始化使用独立seed=42：依次初始化P_G、Kc、分类器；P_G和Kc使用Kaiming normal、fan_out、ReLU，分类器权重Normal(0,0.01)、bias=0。随后创建全零Kd，再把P_G的卷积及BN affine数值复制给独立的P_N参数。Kd和P_N的创建不能消耗额外随机数；构造函数的临时随机初始化也必须避免或隔离并恢复RNG。新头BN的gamma=1、beta=0，running_mean=0、running_var=1、counter=0，按G/N/aux对应建立缓冲区。不沿用NativePyramid v3的−4.6分类偏置。

这使r3与v2在相同数值执行条件下具有相同的初始预测，是代数构造；尚未做完整模型运行对照。复制数值不允许共享Parameter对象或底层可写存储，优化器必须分别包含P_G、P_N各一次。两组参数在第一次更新后即可分化。

Kd从零开始，使初始主头对两路对称读取，同时允许差异路径从首步学习；**最终输出卷积及共同路径Kc均非零初始化。** 若g为A上的上游梯度，则：

~~~text
∂L/∂N = (Kcᵀ + Kdᵀ) g / sqrt(2)
∂L/∂G = (Kcᵀ - Kdᵀ) g / sqrt(2)
~~~

Kd=0时，两路均保留经过Kc的反传通路；Kd自身也可由D与g形成首步权重梯度。此处“保留通路”不等于任意样本、任意ReLU状态下每个参数梯度都非零。

|可训练部分|参数量|
|---|---:|
|P_G的1×1卷积及BN affine|46,208|
|P_N的1×1卷积及BN affine|46,208|
|Kc的7×7卷积|200,704|
|Kd的7×7卷积|200,704|
|主/辅助共享的头部BN affine|128|
|共享四类分类器|260|
|解码器合计|494,212|
|共享W48|65,325,120|
|全模型|65,819,332|

同一BN内部的分域只增加缓冲区；P_G与P_N是两个BN实例，各有gamma/beta。相比247,300参数的原FCN头增加246,912参数；相比JointContext v2增加46,208参数，约为v2全模型的0.07025%。v2本就执行两次投影，拆分本身不增加投影卷积的理论乘加次数，但增加参数、梯度与优化器状态。

全部参数继续使用相同weight decay，因此在P_N=P_G子空间上，投影部分的正则惩罚是旧单投影的两倍；梯度汇合方式和全局裁剪范数也改变。不能把相同初始预测或函数族包含关系写成相同优化轨迹、较低正则目标或40k终点mIoU下界。

## 4. 主损失：所有类别统一使用两图汇总平方Dice

标签定义为0背景、1 EX、2 HE、3 SE、4 MA、255忽略。四类使用独立sigmoid，不加入第五个背景分类通道。

对每类c，令v表示label≠255，y_c表示该类GT，p_c=sigmoid(Z_c)，所有Σ均先覆盖本步两张图的有效像素：

~~~text
P_c = Σ(v y_c)
V   = Σv
ε   = 1e-5

对所有 P_c >= 0，V > 0：
  L_c = 1 - (2 Σ(v p_c y_c) + ε) / (Σ(v p_c²) + P_c + ε)

L_main = (L_EX + L_HE + L_SE + L_MA) / 4
~~~

先筛选有效位置，再执行sigmoid及归约；归约为FP32。不能先对255位置产生非法数再乘零。整个主batch均为ignore时，在模型前向前报错，不能产生无监督的优化或BN更新。合法监督位置出现非有限数也必须显式报错。

这保留原平方Dice的形式，改变跨图归约。当一张图有该类、另一张没有时，两图的负例共同进入同一个分母，负例梯度不再只依赖空图Dice的epsilon分子。

**撤回v1的空类BCE。** 构造两张2048图、全部有效、p=0.5的例子：空类BCE对共同bias的导数为0.5；同一批量有1,000个阳性像素时，Dice对应导数约0.000238，相差约2,100倍。此例并非实测网络梯度，却表明“单位权重自然安全”没有依据；历史SE空阳性更新占49.175%，不能忽略这种切换。

当两张都没有该类时，继续计算1−ε/(Σp²+ε)，不整类跳过，也不额外加BCE、类别权重或难负例项。代价写明：这一情形的梯度可能很弱；有阳性批次中的联合负例监督仍然存在。该选择消除了未校准的强空类惩罚，不声称已经解决所有无病灶图误检。

设A=2Σpy+ε、B=Σp²+P+ε，单个有效logit的导数为：

~~~text
∂L_c/∂z_i = (2 A p_i / B² - 2 y_i / B) p_i(1-p_i)
~~~

该导数对正例非正、对负例非负；这描述独立logit上的方向，**不构成共享网络参数更新后每个像素都改善的证明**。两图soft Dice也不是整个验证集离散mIoU的无偏估计。本次同时验证了一个两像素反例：Dice损失下降而0.5阈值IoU下降，因此不把损失下降写成指标必升的证明。

## 5. M4辅助监督的完整定义

M4仅使用G路径的FG720特征，不新增RGB编码。每步用独立、持久的numpy RandomState(42)抽一个r∈[0.75,1.25)，裁块边长h=8 floor(1024r/8)。抽取4个空间框，两张图共享这些框，最多形成8个裁块实例。

每个坐标使用原helper的规则：

~~~text
offset = 8 * randint(0, floor((2048-h+1)/8))   # 上界不包含
~~~

不能顺手改成包含末端、按类别重采样或每张图分别抽r。裁框坐标除以8得到FG720的整数框；裁出的特征双线性放大至256×256。标签直接从2048画布截取对应h×h区域，不把标签先缩到256。

**先按标签排除全255的裁块实例，再将其余实例拼成一个batch、调用辅助头一次：**

~~~text
crop(FG720) → resize256 → P_G[aux域] → Kc → BN_aux → ReLU → 同一分类器
~~~

辅助logits以FP32双线性放大到h×h，与原裁块标签比较。Kd、P_N不参与此路；辅助路径训练P_G、共同卷积和分类器。保留有效背景裁块，不把“没有病灶”误当成“没有监督”。

辅助损失仍为每个有效实例、每个类别分别计算的平方Dice，ε=1e−5，显式屏蔽255；先四类平均，再对有效实例平均。**辅助损失不跨实例池化；主损失跨两张原图池化。两者均不使用BCE。**

~~~text
L_total = L_main + 0.1 * L_M4
~~~

若8个实例全部被排除，令L_M4=0并跳过辅助头及其BN更新，正常计算有效主损失。不能重抽直到有病灶，也不能再额外除以4。M4只在训练使用，推理不加入裁块预测平均。

## 6. BN状态与精确反传的执行约定

|BN所在位置|独立running统计域|共享内容|
|---|---|---|
|W48各BN|G、N|唯一gamma/beta|
|投影P_G的BN|G、aux|P_G内唯一gamma/beta|
|投影P_N的BN|N|独立gamma/beta，不与P_G共享|
|7×7卷积后的BN|main、aux|唯一gamma/beta|

所有BN设eps=1e−5、momentum=0.1。训练归一化使用有偏batch方差，running_var写入无偏估计。主干G/N初始缓冲区分别复制同一预训练BN状态，头部缓冲区按第3节初始化；推理分别读取对应域的running统计，主预测只读取main头域。辅助路径更新与主路径分离。

BN的FP32执行必须显式实现：关闭autocast，将输入、affine与缓冲区保持FP32计算，再将输出转回该BN输入的激活dtype。只写“running buffers为FP32”不能替代这一计算约定。

训练采用**单设备、每次编码器前向物理batch=2**。不能沿用v3逐图循环或普通micro batch1累积来替代该BN语义。本版不同时保留DDP/SyncBN作为另一套可选实现。

为避免同时保留两路完整主干反传图，使用“两阶段编码器重计算”。每一步流程如下：

1. 校验图像、标签和有效监督，生成两个视图及本步M4框；仅清空一次梯度，参数保持不变。
2. 依次在no_grad下编码G、N，但BN仍使用训练批统计，各自域的running统计只更新一次。保留每路四个输出特征，将其detach后设为需要梯度的叶节点。
3. 在这些特征叶节点上执行完整解码器、主损失和辅助损失，反传一次。保留解码器参数梯度和每路四个特征伴随梯度g_G、g_N。g_G必须包括主路与M4的贡献。释放解码器反传图。
4. 按相同输入、参数、精度重算G主干，再重算N主干；每路均为物理batch2。BN仍用当前批统计，但**禁止重算写入running_mean、running_var及计数器**。分别对四个输出调用带对应g的向量—雅可比反传，累加到共享主干参数梯度，逐路释放图。
5. 所有梯度合并后统一clip一次，再执行唯一一次SGD更新。

**混合精度边界是强制约定：** 每次编码前向、解码前向及编码重算各自进入新的autocast上下文，全部设置cache_enabled=False；退出上下文后再backward。禁止用一个外层autocast包住no_grad缓存阶段和有梯度阶段。仅使用torch.no_grad，不用inference_mode缓存。

本机PyTorch 2.6.0 CPU已复现：缓存开启时，no_grad中产生的低精度权重可被后续反传阶段复用，导致卷积权重缺失梯度；即使BN affine使最终输出仍有requires_grad，也不能据此判定主干梯度正常。预检必须逐个核对预期主干参数的梯度，而不只检查输出标志。

只读BN重算的固定实现方式是：将当前域running_mean/var复制到局部临时张量，以training=True调用F.batch_norm，允许写入临时副本后丢弃，不修改持久缓冲区和计数器。不能临时修改整个模块的训练状态，也不能在反传图存活时改写持久BN状态进行“补偿”。

链式法则给出的主干梯度为J_Gᵀg_G+J_Nᵀg_N。缓存时detach是计算图分段，不能省略第4步而变成冻结主干；也不能再除以2。第4步的BN不能切eval。域必须作为显式参数传递，不能依赖可能在重算前改变的全局“当前域”变量。

固定模型没有编码器dropout或随机深度。若实现擅自增加随机算子，以上重算条件便不再自动成立。每完成u次正常更新，主干G/N、P_G的G域、P_N的N域和头部main的计数器相对初始化应各增加u；P_G和头部的aux计数器增加量均不超过u且彼此相等。重算对所有计数器增加量必须为0。

上述梯度等式是相同前向条件下的实数链式法则；实际BF16/CUDA实现仍需验证缓存与重算的一致性。当前没有完整模型的显存测量，不能用旧单路2048的显存读数宣称本模型已满足某张GPU的容量。

## 7. 固定训练配方与计算预算

|项目|固定值|
|---|---|
|优化器|SGD，lr=0.005，momentum=0.9，weight_decay=0.0005，dampening=0，nesterov=False|
|参数组|所有可训练参数只注册一次；无主干/新头LR倍率|
|更新数与batch|40,000；每更新2张原图，两视图各物理batch2|
|随机性|数据seed42；新头隔离seed42；M4独立RandomState42|
|梯度裁剪|global L2 norm≤5，完整梯度汇合后、SGD前执行一次|
|精度|卷积BF16 autocast(cache_enabled=False)，各阶段独立上下文；主参数、BN计算/统计、优化器状态、loss使用FP32|
|融合数值|C/D计算及两卷积分支求和FP32；卷积按BF16策略输入；最终logits插值FP32|
|额外训练机制|无EMA、无教师、无任务预训练、无参数冻结、无FP16 scaler跳步|

零基更新t=0,…,39999的学习率：

~~~text
lr(t) = 0.005 * (1 - t/40000) * warmup(t)
warmup(t) = 1e-6 + (1-1e-6)*t/1500,  t < 1500
            1,                       t >= 1500
~~~

已检查边界：t=0为5e−9，1499为0.00480941658654，1500为0.0048125，39999为1.25e−7。每次SGD前设定该步lr，不允许scheduler调用先后造成偏移。

保留clip=5是相对05的修正：当前40k记录不足以证明裁剪导致失败，删除已有有限梯度约束也没有证据支持。裁剪仅限制本步梯度范数，不是训练或泛化稳定性的保证。发现非有限梯度不能通过静默跳步、回滚重试或更换损失来凑满40k。

训练合计80,000原图次、160,000语义编码视图次。由于编码器重计算，实际编码器前向对应320,000图次；这不增加数据或SGD次数，但增加计算。两尺度输入面积合计为1024²+2048²，是原B0单次1024编码的5倍；额外反传重算还增加执行成本。因此本方案满足相同步数与原图batch，**不声称相同FLOPs或运行时间**。
