# HRDecoder 眼底病灶分割实验档案

此仓库归档 `experiment` 中各轮实际保留的实验数据、训练代码、配置、日志和实验说明，包含成功、失败、停止和历史方案记录。快照日期：2026-10-31。原大创项目尚未结题。

## 阅读入口

- [实验目录](experiments/)：按本地原目录组织的代码、日志、配置和实验 MD。
- [完整收录清单](archive_manifest.json)：每个收录文件的原路径、存储位置和 SHA-256。`_archive_contents/` 保存原压缩包逐项筛选后的内容，避免遗漏仅存于压缩包的实验文件。
- [实验数据下载](https://github.com/roxycon-dev/experiment-archive/releases/tag/data-20261031)：较大的指标文件、采样记录、预测/标签和图像数据。
- [模型权重下载](https://github.com/roxycon-dev/experiment-archive/releases/tag/weights-20261031)：完整权重及确有必要保留的权重片段。
- [模型索引](model_index.csv)：原始权重路径与下载文件的对应关系。
- [归档统计](archive_summary.json)、[下载包校验值](release_assets.json)。

## 覆盖与边界

共收录 69,830 个文件路径（包含压缩包内文件和重复副本映射），其中 25,041 个文本文件可在仓库直接浏览。相同内容只存储一次，每个原路径仍在清单中保留。44 个传输片段经完整文件及各分片 SHA-256、布局和长度核对确认与完整权重对应，清单标明其完整权重路径。

按所有者要求，论文稿件、论文图表、文献附件与写作审稿材料未收录；论文工作目录中实际的实验数据、评估证据、训练脚本与模型权重单独保留。排除无关课程资料、Git 内部文件、运行缓存、未完成传输和环境安装包。凭据仅在上传副本中脱敏，本地原文件未修改。

本仓库是历史实验档案，并非统一训练入口。各轮的划分、训练预算、运行环境和指标口径可能不同，请先阅读对应实验说明。历史记录中的“最佳”以记录日期为准，不能直接混合比较。

## 下载与恢复

下载仓库后运行（Python 标准库即可）：

```powershell
python restore_archive.py --phase data --output restored
python restore_archive.py --phase weights --output restored
```

脚本按清单下载并验证资产及对象 SHA-256，再恢复原目录结构。权重与实验数据分批发布。未发布的阶段会明确报错，不会被当成下载成功。若只需阅读记录，无需下载权重。

## 数据来源

本档案包含 DDR、IDRiD 及各轮记录中注明的其他公开眼底数据集的实验文件。原数据集的许可和使用条件仍适用；本仓库不为第三方数据或代码授予新的许可。第三方代码保留已有 LICENSE/NOTICE。未为此仓库增加统一开源许可证。
